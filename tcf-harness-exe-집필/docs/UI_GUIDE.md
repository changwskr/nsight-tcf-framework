# 문체·구성 가이드 — 풍부한 책 집필

> 파일명 `UI_GUIDE.md`는 시드 호환용. 실제로는 **책 문체 가이드**다.

## 이 하네스의 제품

제품은 `ztcfbook` **본문**이다. IN/OUT 핸드오프·체크리스트 파일이 제품이 아니다.

## 풍부함 (필수)

각 장(특히 실습·핵심 장)은 다음을 포함한다.

1. **여는 글** — 이 장이 푸는 문제, 누가 읽는가, 읽고 나면 무엇을 할 수 있는가
2. **개념** — 용어를 풀어서 설명 (한 줄 정의 + 왜 중요한지)
3. **전체 그림** — 흐름도(text/mermaid)로 End-to-End
4. **계층·파일 지도** — 실제 패키지/경로 표
5. **코드 산책** — 저장소 실코드 발췌 + 줄거리 설명 (복붙만 하지 말 것)
6. **요청·응답** — JSON 예시 (필드명은 코드와 일치)
7. **실수 박스** — 자주 하는 실수와 증상·해결
8. **검증** — 기동·curl·테스트·로그에서 무엇을 볼지
9. **장 요약** — 핵심을 다시 묶기
10. **이전·다음 · 출처 색인**

얇은 “표 세 개로 끝” 장은 거부한다. 독자가 동료에게 설명할 수 있을 만큼 쓴다.

## 문체

- 존대·설명체. 마케팅 문구·이모지 남발 금지.
- 절 ID는 목차와 맞추되, **소절을 충분히** 둔다.
- 코드 블록에 경로를 주석으로 밝힌다. 예: `// sv-service/.../SvCustomerHandler.java`
- 가상 예시면 `(예시)`를 붙인다.

## 에디션

| 에디션 | 톤 |
|--------|-----|
| ztcfbook | 업무·운영 개발자 — 설계·운영·코드 균형 |
| ztcfbook-m | 더 쉬운 문장 + 비유 (승인 후) |
| ztcfbook-h | + Master 해설·다이어그램 (승인 후) |

## 금지

- IN/OUT 디렉터리 생성·채우기를 본 작업의 목표로 삼기
- 출처 없는 식별자 창작
- `_gen-book-*.cjs` 무단 실행
- 한 런에서 무관한 여러 장 전면 개편
