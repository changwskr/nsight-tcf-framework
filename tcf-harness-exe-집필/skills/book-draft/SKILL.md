# Book Draft

Prerequisites: approved outline and `draft-plan.md`.

1. Read every source listed for the sections being written.
2. Write or update only the approved target paths under `../ztcfbook` (or approved edition).
3. Follow `docs/UI_GUIDE.md` (style) and the chapter template.
4. Keep section IDs, navigation links, and source index consistent with TOC.
5. Record commands and changed paths in `verification-report.md`.

Do not run `_gen-book-*.cjs` without explicit approval. Do not expand into unapproved chapters.
