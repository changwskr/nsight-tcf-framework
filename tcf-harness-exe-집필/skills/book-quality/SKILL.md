# Book Quality

1. Verify the chapter is linked from `00-목차.md` (or note intentional draft status).
2. Resolve relative previous/next links and cited source paths (existence check).
3. Apply style checklist from `docs/UI_GUIDE.md`.
4. Note required follow-up for `-m`/`-h` mirrors if only base was updated.
5. Write `qa-report.md` with PASS/FAIL and release recommendation.

Do not approve release when fact-check is incomplete or generator overwrite risk is undisclosed.
