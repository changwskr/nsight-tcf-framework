# Book Research

1. Confirm edition target (`ztcfbook` default).
2. Read `00-목차.md` and the matching entry in `_gen-book-chapters.cjs` (or `-m`/`-h` maps).
3. Collect candidate sources from the framework source map; open each path that will be cited.
4. Compare design docs vs code for the chapter topic; note gaps.
5. Write `analysis-summary.md` with inventory and open questions.

Do not draft chapter prose in this skill. Do not invent missing sources.
