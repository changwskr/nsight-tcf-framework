# Chapter Template — 풍부한 장

`../ztcfbook/{편}/{slug}.md` 기본 골격. **표를 채우는 것으로 끝내지 말고** 각 절을 서술로 채운다.

```markdown
# 제{N}장. {제목}

| 항목 | 내용 |
| --- | --- |
| **편** | … |
| **장** | 제{N}장 |
| **독자** | … |
| **이 장을 읽으면** | … |

## 들어가며

{문제 상황 · 왜 TCF에서 이 주제가 중요한지 · 장 로드맵}

## {N}.1 {절}

### 한 줄 정의
…

### 자세히
{2~6 문단}

### 그림 / 표
…

### 코드로 보기
\`\`\`java
// path/to/RealClass.java
\`\`\`

### 실수하기 쉬운 점
- …

## {N}.2 …

## 디버깅 · 검증

{기동, curl, 로그, 테스트}

## 장 요약

- …

## 이전 · 다음

| | |
| --- | --- |
| ← 이전 | […](…) |
| → 다음 | […](…) |

## 출처 색인

| 절 | 출처 |
| --- | --- |
| {N}.1 | \`zman/…\`, \`sv-service/…\` |
```

소절(`{N}.2.1`)을 적극 사용한다. IN/OUT 산출물 템플릿은 사용하지 않는다.
