# PDMG EOS 네이밍

`pdmg-service`의 MG 규칙을 EOS 도메인에 맞춘 요약입니다.

| 구분 | 규칙 | 예시 |
|------|------|------|
| 업무코드 | `EOS` | — |
| 앱/세부 | `co` / `a` | 공통·상세 A |
| 패키지 | `nhnis.eos.<app>.<sub>.…` | `nhnis.eos.co.a` |
| 서비스 ID | `eos` + `co` + `a` + `NNNN` + `S0/C0/…` | `eoscoa0100S0` |
| Mapper | `rdw.eos.co.a/` | `eoscoa0100-ORA.xml` |
| Main | `nhnis.eos.PdmgEosApplication` | port `8082` |
