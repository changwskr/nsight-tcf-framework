# 샘플 요구사항 — 자산평가 목록 조회 (연습용)

## 목적

자산평가(AV) 업무에서 평가 목록을 조회하는 온라인 조회 거래를 추가한다.

## 기능 요구

1. 사용자는 평가일자·상품코드 조건으로 자산평가 목록을 조회할 수 있어야 한다.
2. 결과는 페이징되어야 한다.
3. ServiceId는 기존 AV 모듈 명명규칙을 따른다. (확정 전 Gap으로 관리)

## 비기능

- 조회 전용 (DB 변경 없음)
- 표준 요청·응답 전문 사용
- 거래 로그·감사 로그 기록

## 제약

- 운영 DB DDL 직접 실행 금지
- 승인 없는 Git Push 금지

## 미확정 (가정/Gap)

- 실제 테이블·컬럼 소유 도메인: DA 확인 필요
- 확정 ServiceId: 기존 `av-service` 코드 조사 후 확정
