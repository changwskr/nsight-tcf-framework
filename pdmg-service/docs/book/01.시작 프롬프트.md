이 프로젝트는 「PDMG 애플리케이션 아키텍처와 개발 가이드」 집필 프로젝트다.

본문 집필을 시작하기 전에 프로젝트 루트의 다음 문서를 반드시 읽어라.

1. AGENTS.md
2. BOOK-WRITING-RULE.md
3. SOURCE-MAP.md
4. BOOK-TOC.md

그리고 sources 또는 docs 디렉토리의 원천자료 구조와
pdmg-ui, pdmg-fw, pdmg-service, pdmg-jwt 소스 구조를 확인하라.

아직 본문은 작성하지 마라.

먼저 다음만 점검하라.

- 전체 책의 1~33장 흐름
- 1장의 역할
- 1장 SOURCE-MAP
- 1장에서 사용할 기본자료
- 재분석 자료
- 다이어그램 자료
- 실제 소스로 검증해야 할 사항
- 1장과 2장의 경계

중요:
원천 문서를 요약하는 것이 아니라
실제 PDMG 아키텍처를 설명하는 책을 만드는 작업이다.

확인이 끝나면
1장 집필 준비가 되었는지만 간단히 보고하라.
