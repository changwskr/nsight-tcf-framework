# 제26장. 예외처리와 표준 오류 — ASCII 확장본 상세목차

> **최우선 AS-IS 판정**
>
> - 성공은 `{hdr_nhnis,dto}`, NH_NIS_ERR_DTO 오류는 `{hdr_nhnis,result}`다.
> - GlobalExceptionHandler는 TCF ON에서 활성화되고 현재 네 예외만 명시 처리한다.
> - BizException은 current HTTP 500이며 YAML 메시지와 미연결이다.
> - 일반 Runtime/DB 예외 catch-all Handler는 확인되지 않았다.
> - Filter 400/401 sendError는 MVC Advice를 우회한다.
> - Global/Legacy 두 ControllerAdvice가 공존하고 명시 Order가 없다.
> - Legacy NhBaseException Handler에는 null switch와 Stack Trace 외부노출 위험이 있다.
> - ImageLog는 최종 result 오류를 기록하지만 업무 Transaction 밖의 별도 JDBC 작업이다.
>
> **Source Drift**
>
> `36.프로그램 예외 처리 방법.md`와 `64.Exception 다이어그램.md`의 완성형 흐름은 STANDARD/TO-BE로 보고, `11.예외처리-1.md`, `22.exceptionCode처리-1.md`, `26.시스템후처리-1.md`의 재분석을 current AS-IS로 우선한다.
