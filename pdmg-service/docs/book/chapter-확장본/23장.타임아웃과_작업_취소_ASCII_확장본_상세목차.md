# 제23장. 타임아웃과 작업 취소 — ASCII 확장본 상세목차

> **목차 작성 기준**
>
> 핵심 근거: `chapter/23장.타임아웃과 작업 취소.md`, `20.타임아웃-1.md`, `20.타임아웃.md`, `2026-08-09-pdmg-online-timeout-executor-design.md`, `20.Tranaactional-rdwTransactionManager-Begin-1.md`, `16.TCF-OnlineTransactionController-1.md`, `71.Transaction Manager.md`.
>
> **최우선 AS-IS**
> - TCF ON+timeout enabled: DefaultOnlineTimeoutExecutor가 Worker/Future/outer Transaction을 소유한다.
> - Request timeout: `future.cancel(true)` 후 504 `FW_TIMEOUT`.
> - cancel(true)는 강제 kill/JDBC 즉시종료가 아니다.
> - Worker가 제어권을 되찾아 deadline/interrupt를 검사한 뒤 outer TX가 rollback되어야 실제 DB rollback 완료다.
> - Pool 20 + Queue 100 포화는 503 `FW_OVERLOADED`다.
> - 최신 Chapter23 기준은 공통 5000ms이며 서비스별 override는 자료시점 충돌로 실제 Source 재검증 전 확정하지 않는다.
> - 핵심 Mapper SQL Statement Timeout은 현재 확인되지 않았다.
> - `mgcoa5530Service`의 interrupt 후 DAO 계속 가능성은 P0 취소협력 결함이다.
