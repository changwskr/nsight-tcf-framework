# 제19장. DAO와 MyBatis Mapper — ASCII 확장본 상세목차

> **목차 작성 기준**
>
> 이 장은 `23.DAO-1.md`, `24.DAO-Mapper-1.md`, `24.DAO-Namespace-1.md`, `60.DAO 다이어그램.md`를 핵심 근거로 작성한다.
>
> **AS-IS 고정 사실**
>
> - DAO는 `nhnis.mg.co.a.persistence.dao`의 MyBatis Mapper Interface이며 Java 구현 클래스가 없다.
> - 현재 핵심 DAO는 4개, DAO Method/Mapper Statement는 12개다.
> - DAO에는 `@RDWMapper`가 붙고, `@MapperScan(basePackages="nhnis.mg.co.a.persistence.dao", sqlSessionTemplateRef="rdwSqlSessionTemplate")`이 Proxy Bean을 생성한다.
> - `rdwDataSource → rdwSqlSessionFactory → rdwSqlSessionTemplate → DAO Proxy`로 연결되며 `rdwTransactionManager`도 같은 DataSource를 사용한다.
> - Mapper XML은 `classpath*:rdw.*/*.xml`로 로딩되며 현재 `rdw.mg.co.a`에 4개 `-ORA.xml`이 있다.
> - `DAO FQCN = XML namespace`, `DAO method = statement id`가 현재 모두 일치한다.
> - 사용자 입력 바인딩은 `#{}`이며 위험한 `${}`는 현재 확인되지 않았다.
> - DAO 입력은 `Map<String,Object>`, 목록결과는 `List<Map<String,Object>>`, count/exists/C/U/D는 `int`다.
> - Mapper XML/전역설정에 SQL Statement Timeout이 없다.
> - DAO/Mapper 실제 실행 전용 통합 Test가 없다.
> - `mgcoa8888-ORA.xml`은 `REQUEST_MSG/RESPONSE_MSG`를 조회하지만 로컬 H2 `TB_FW_IMAGE_LOG`에는 해당 Column이 없어 실행오류 가능성이 있다.
> - 8888/9000 다건삭제의 IN 목록 최대크기 제한이 없어 Oracle 1,000개 제한 위험이 있다.
> - `MybatisLogInterceptor`가 sqlId·parameter·elapsed를 DEBUG로 기록하며 Parameter Masking/최대길이 제한은 확인되지 않는다.
> - TCF ON+Timeout ON에서 DAO는 Worker `TransactionTemplate`이 연 외곽 TX에 참여하며, 5초 HTTP Timeout은 JDBC Statement Timeout이 아니다.
