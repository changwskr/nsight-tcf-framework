# 제27장. 이미지로그와 GUID 추적 — ASCII 확장본 상세목차

> **집필 기준**
>
> 이 장은 `chapter/27장.이미지로그와 GUID 추적.md`, `68.트랜잭션 이미지로그 다이어그램.md`, `69.GUID 아키텍처 다이어그램.md`를 중심으로 하고 `16.Service Context-1.md`, `26.시스템후처리-1.md`, `55.시스템선후처리다이어그램.md`, `22.Business-Service-1.md`, `23.DAO-1.md`, `24.DAO-Mapper-1.md`로 current AS-IS를 교차검증한다.
>
> **최우선 AS-IS**
>
> - GUID는 `hdr_nhnis.sys_comm.std_gbl_id`, `ServiceContext.guid`, MDC/ThreadContext를 연결하는 상관키다.
> - GUID는 인증 Credential, 업무 PK, DB Transaction ID, Idempotency Key가 아니다.
> - 요청 ImageLog는 `ServicePreventionInterceptor.preHandle() → ImageLogHandler.preImagelog()`에서 시작한다.
> - pre 저장은 단순 INSERT가 아니라 **UPDATE-first → 0건 INSERT → DuplicateKey 시 재-UPDATE**다.
> - 동일 GUID 재사용은 이전 Response/Exception을 초기화해 감사흔적을 덮을 수 있다.
> - 최종 응답 전문은 `ResponseBodyArgumentResolver`가 `ServiceContext.responseBody`에 저장하고 `afterCompletion()`이 ImageLog를 완료한다.
> - 처리된 표준 오류는 `ex==null`이어도 `postImagelog()`가 `result.stdErrCode`를 읽어 Exception 컬럼을 갱신한다.
> - 미처리 예외는 `exceptionImagelog()`를 사용하며 UPDATE 0건이면 INSERT까지 한다.
> - 정상 post UPDATE 0건은 경고만 남기고 INSERT 복구하지 않는 비대칭이 있다.
> - ImageLog는 별도 DataSource가 아니라 Primary `rdwDataSource`를 사용하지만 pre/post 호출 위치상 업무 Transaction 밖의 별도 JDBC 기록이다.
> - 명시적 ImageLog 전용 TransactionManager/REQUIRES_NEW는 확인되지 않았다.
> - ImageLog 저장 실패는 fail-open으로 본업무를 계속한다.
> - `mgcoa8888S0/D0`도 일반 거래처럼 자기 ImageLog를 만든다.
> - `mgcoa8888D0`이 현재 요청 GUID를 삭제하면 자기 pre 행이 사라지고 정상 post는 0건 경고로 끝날 수 있다.
> - `resolveWireMsg()`는 전문을 최대 20,000자로 제한하지만 필드별 Token/PII 마스킹은 확인되지 않았다.
> - 자동 Retention/Partition/Archive/Purge 정책은 현재 확인되지 않았다.
> - Timeout Worker는 GUID/MDC를 전파하지만 현재 동일 mutable `ServiceContext` 객체를 공유할 수 있다.
>
> **Source 정정**
>
> - 다이어그램의 “별도 ImageLog DB/Transaction” 표현은 current Source에 맞춰 “같은 Primary RDW DataSource를 사용하되 업무 TX 밖에서 호출되는 JDBC 작업”으로 교정한다.
> - GUID 다이어그램의 외부시스템 전파는 좋은 표준/권장 패턴이지만 실제 모든 외부 Client가 적용됐다고 단정하지 않는다.
> - 런타임 DDL은 current 장 원문에서 확인되나 운영 Schema 변경 방식으로 권장되는 것은 아니다.
>
> **장 경계**
>
> - 제26장의 예외 코드/Handler 상세는 반복하지 않고 ImageLog에 최종 결과가 어떻게 남는지만 사용한다.
> - 제28장의 Thread/Pool/SQL p95 대시보드 상세는 선점하지 않고 GUID 기반 한 거래 추적과 ImageLog 자체 운영지표까지만 다룬다.
