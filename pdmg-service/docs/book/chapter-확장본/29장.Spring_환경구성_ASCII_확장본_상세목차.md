# 제29장. Spring 환경구성 — ASCII 확장본 상세목차

> **집필 기준**
>
> 최우선 근거는 `28.Spring 환경구성정보-1.md`, `31.Spring-환경파일-중심-소스연관성.md`, `29.환경구성정보와 소스 연관성-이미지순서.md`, `29장.Spring 환경구성.md`다. `*-1.md`의 재분석을 기본설명·다이어그램보다 우선한다.
>
> **현재 핵심**
> - central config: `pdmg-service/application.yml`
> - default profile: local
> - common H2 + `spring.sql.init.mode=always`
> - TCF ON, Timeout ON 5000/20/100, Filter ON, legacy-web ON
> - local/dev 모두 `jwt.enabled=false`지만 실제 JWT 분기는 active==local 여부
> - prod profile document 미확인
> - `application-fw-defaults.yml` 자동 로딩 근거 없음
> - `exceptionCode.yml` explicit import, 동일 이름 두 resource 자동 merge 근거 없음
> - `spring.datasource.rdw` → Hikari/MyBatis/TM/ImageLog/Monitor
> - 일반 dynamic refresh 근거 없음
