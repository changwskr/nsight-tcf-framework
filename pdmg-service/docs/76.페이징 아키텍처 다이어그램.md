## PDMG 페이징 아키텍처 다이어그램

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 1. 화면 / API Client                                                │
│                                                                      │
│ 요청                                                                 │
│ {                                                                    │
│   "검색조건": "...",                                                 │
│   "pageNo": 2,          ← 1부터 시작                                │
│   "pageSize": 20        ← 최대 100                                  │
│ }                                                                    │
│                                                                      │
│ ※ offset은 클라이언트가 전달하지 않음                               │
└───────────────────────────────┬──────────────────────────────────────┘
                                │ HTTP 요청
                                ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 2. TCF / Controller / Handler                                       │
│                                                                      │
│ Filter → Interceptor → TCF → Handler → Facade                       │
│                                                                      │
│ · 헤더 검증                                                          │
│ · 거래 통제                                                          │
│ · 타임아웃 적용                                                      │
│ · Service ID에 해당하는 Handler 선택                                │
│ · 입력 전문을 S0DTOin으로 변환                                      │
│                                                                      │
│ 페이징 값은 변경하지 않고 업무 계층으로 전달                        │
└───────────────────────────────┬──────────────────────────────────────┘
                                ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 3. Facade — 트랜잭션 경계                                           │
│                                                                      │
│ @Transactional(                                                     │
│     transactionManager = "rdwTransactionManager",                   │
│     readOnly = true                                                  │
│ )                                                                    │
│                                                                      │
│ · 목록 COUNT와 데이터 조회를 하나의 트랜잭션에서 수행              │
│ · Service 호출                                                       │
└───────────────────────────────┬──────────────────────────────────────┘
                                ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 4. Business Service — 페이징 정책 담당                              │
│                                                                      │
│ 입력 보정                                                            │
│                                                                      │
│ pageNo                                                               │
│   ├─ null 또는 0 이하 → 1                                           │
│   └─ 정상값           → 요청값                                      │
│                                                                      │
│ pageSize                                                             │
│   ├─ null 또는 0 이하 → 기본값                                      │
│   ├─ 1 ~ 100          → 요청값                                      │
│   └─ 100 초과         → 100                                         │
│                                                                      │
│ offset = (pageNo - 1) × pageSize                                    │
│                                                                      │
│ 예: pageNo=2, pageSize=20                                            │
│     offset=(2-1)×20=20                                               │
│     조회 범위=21번째 행부터 20건                                    │
└───────────────────────────────┬──────────────────────────────────────┘
                                │
                ┌───────────────┴────────────────┐
                │                                │
                ▼                                ▼
┌───────────────────────────────┐  ┌───────────────────────────────────┐
│ 5-1. 전체 건수 조회           │  │ 5-2. 현재 페이지 데이터 조회     │
│                               │  │                                   │
│ DAO.*_S0_count(param)         │  │ DAO.*_S0(param)                   │
│                               │  │                                   │
│ SQL ID                        │  │ SQL ID                            │
│ {serviceId}_S0_count          │  │ {serviceId}_S0                    │
└───────────────┬───────────────┘  └─────────────────┬─────────────────┘
                │                                    │
                ▼                                    ▼
┌───────────────────────────────┐  ┌───────────────────────────────────┐
│ 6-1. COUNT Mapper SQL         │  │ 6-2. LIST Mapper SQL              │
│                               │  │                                   │
│ SELECT COUNT(*)               │  │ SELECT *                          │
│   FROM 업무테이블             │  │   FROM (                          │
│  WHERE 공통검색조건           │  │     SELECT a.*, ROWNUM rnum       │
│                               │  │       FROM (                      │
│ 결과                          │  │         SELECT ...                │
│ totalCount = 95               │  │           FROM 업무테이블        │
│                               │  │          WHERE 공통검색조건       │
│                               │  │          ORDER BY 고정정렬        │
│                               │  │       ) a                         │
│                               │  │      WHERE ROWNUM                 │
│                               │  │            <= offset + pageSize  │
│                               │  │   )                               │
│                               │  │  WHERE rnum > offset              │
└───────────────┬───────────────┘  └─────────────────┬─────────────────┘
                │                                    │
                └───────────────┬────────────────────┘
                                ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 7. Service — 응답 조립                                              │
│                                                                      │
│ rows        = 현재 페이지 데이터                                    │
│ size        = rows.size()                                            │
│ totalCount  = COUNT SQL 결과                                         │
│ totalPages  = ceil(totalCount / pageSize)                            │
│             = (totalCount + pageSize - 1) / pageSize                │
│                                                                      │
│ 예:                                                                  │
│ totalCount=95, pageSize=20                                           │
│ totalPages=5                                                         │
└───────────────────────────────┬──────────────────────────────────────┘
                                ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 8. 출력 DTO — *S0DTOout                                             │
│                                                                      │
│ {                                                                    │
│   "목록DTOSub0": [ ...현재 페이지 데이터... ],                      │
│   "size": 20,                                                        │
│   "pageNo": 2,                                                       │
│   "pageSize": 20,                                                    │
│   "totalCount": 95,                                                  │
│   "totalPages": 5                                                    │
│ }                                                                    │
└───────────────────────────────┬──────────────────────────────────────┘
                                ▼
                   화면의 페이징 컴포넌트 표시
```

### 계층별 책임

```text
Client
 └─ pageNo, pageSize, 검색조건 전달
       │
DTOin
 └─ 외부 페이징 계약 정의
       │
Facade
 └─ readOnly 트랜잭션 경계
       │
Service
 ├─ pageNo/pageSize 보정
 ├─ pageSize 최대 100 제한
 ├─ offset 계산
 ├─ count/list 호출
 └─ totalPages 및 응답 DTO 조립
       │
DAO
 └─ MyBatis Statement 호출
       │
Mapper XML
 ├─ COUNT SQL
 ├─ 페이지 LIST SQL
 ├─ 공통 WHERE
 └─ 안정적인 ORDER BY
       │
Database
 └─ 필요한 페이지 데이터만 반환
```

### 핵심 설계 규칙

```text
[허용]
pageNo/pageSize → Service 보정 → DB 페이징 → 현재 행만 반환

[금지]
DB 전체 조회 → Java List.subList() → 일부 데이터만 반환

[필수]
COUNT SQL의 WHERE == LIST SQL의 WHERE
LIST SQL에는 고정 ORDER BY 적용
pageSize ≤ 100
offset은 Service에서 계산
```

### 대용량·깊은 페이지 확장 구조

```text
일반 화면
  └─ Offset 페이징
       └─ pageNo + pageSize
            └─ 특정 페이지 이동 가능

무한 스크롤 / 매우 깊은 페이지
  └─ Keyset 페이징 검토
       └─ lastRequestTime + lastGuid + pageSize
            └─ 이전 페이지의 마지막 키 이후부터 조회
```
