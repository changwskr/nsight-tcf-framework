PPT 통합본 1~11장을 설계 실무용 가이드로 재구성한 세트다. 분석 MD가 ‘무엇을 담았는지’라면, 본 가이드는 ‘어떻게 설계·검증할지’를 다룬다.

## 사용 방법

1. 해당 **장(파트)** 가이드의 원칙·결정 규칙·체크리스트로 설계안을 작성한다.
2. 링크된 **방법론 폴더(01~06)** 분석 MD로 상세·도식·표를 보강한다.
3. 10·11장은 PPT 본문이 약하므로 **가이드 + 방법론**을 실질 기준으로 삼는다.
