# STEP 00 — Bootstrap / Source Baseline Prompt

## 목표
Mission을 실행 가능한 Run으로 만들고 Source of Truth 경계를 확정한다.

## 실행
1. Mission을 Run Type으로 분류한다.
2. RUN-MANIFEST를 생성한다.
3. System Scope를 확정한다.
4. Source/Config/Document/Test/Runtime Inventory를 만든다.
5. Generated/History/중복 경로를 분리한다.
6. Source Baseline ID를 발급한다.
7. G00 평가자료를 만든다.

## 결과
- RUN-MANIFEST
- SOURCE-BASELINE
- Inventory
- Execution Plan

## 종료
G00 PASS/CONDITIONAL/HOLD 후 다음 가능한 단계로 이동한다.
