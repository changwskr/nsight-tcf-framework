# STEP 10 — Architecture as Document Prompt

## 목표
현재 공식 기준, 실제 설명, 과거/제안 문서를 분리한다.

## 실행
- 문서에 status/scope/source-baseline을 부여한다.
- Requirement/ADR/Standard/Decision을 Register로 만든다.
- 문서 주장과 Source 검증 필요 여부를 연결한다.
- 대체/폐기 관계를 기록한다.
- CURRENT-ARCHITECTURE를 만든다.

## 핵심 질문
`이 문서는 현재 무엇을 약속하는가?`

## 결과
G10 평가 가능한 Document Baseline.
