# Program Definition of Done

하나의 Program은 다음이 모두 완료되어야 개발 완료로 본다.

1. Requirements
2. Program / Service Registry
3. PDMG Runtime Architecture
4. Logical / Physical Data Design
5. DTO / Message Contract
6. Backend Detail Design
7. UI Detail Design
8. Backend Implementation
9. UI Implementation
10. Unit / Contract / Integration / E2E Test
11. Security / NFR / Operation Review
12. Conformance / Traceability / Baseline

최종 추적성:

Requirement → Program → Service → UI → DTO → Handler → Facade → Service
→ Rule/Algorithm → DAO → Mapper → SQL → Table → Test
