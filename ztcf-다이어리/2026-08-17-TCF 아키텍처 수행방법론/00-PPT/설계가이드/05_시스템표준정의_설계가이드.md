# Part A — Top-down 구조 이해

## A1. 핵심 결론

이 장은 **서버를 무엇으로 부를지·어디에 무엇을 둘지**를 고정한다.  
IP·스펙을 쓰기 전에 Hostname·FS·계정·포트 Baseline을 맞춘다.

```text
법인·앱·플랫폼·환경·용도·순번
        │
        ▼
유일·검증 가능한 Host (12자리)
        │
        ▼
FS · 계정 · 포트와 동일 인벤토리
        │
        ▼
배포 · 개통 · DR · 모니터 정합
```

```text
시스템 표준 (5장)
        │
        ├─ Hostname (고정 12자리)
        ├─ 파일시스템 (표준 FS · 3분류 · 예외표)
        ├─ 사용자 계정 (환경·역할 분리)
        └─ 서버 포트 (현황표 · 충돌 검사)
```

### 이 가이드가 답하는 것 / 답하지 않는 것

| 답하는 것 (절차) | 답하지 않는 것 |
|---|---|
| 12자리 **조립·검증 순서** | shall·코드표 원문 → **정의서 05 Part B** |
| FS·계정·포트 **기입·교차검증** | Zone·레이어드 → 02 |
| 초보자 실수·미니 예제 | 논리→물리 매핑 전문 → 03 · Drill → 11 |

### 읽는 순서

```text
A1 → A2 큰 그림 → A3 용어 → Part B Step 1~7 → 예제·실수 → 정의서 Part B로 규범 확인
```

## A2. 큰 그림 · 최상위 박스

```text
05 Standard
        │
        ├─ Hostname ──► CMDB · DNS · 인벤토리
        ├─ FS        ──► OS · 스토리지 경로
        ├─ Account   ──► 보안 · 운영 계정표
        └─ Port      ──► FW · LB · 개통
                │
                ▼
        03 물리 목록과 불일치 → 배포·개통 중지
```

| 축 | 이 장에서 할 일 | 상세 위임 |
|---|---|---|
| Hostname | 12자리 조립·DR 순번·CMDB 대조 | 코드표·정규식 → 정의서 |
| FS·계정·포트 | 표준/예외·분리·현황표 기입 | 분석 MD · 정의서 B4~B6 |
| 교차검증 | 03·인벤토리 Gate | 03 · 11 모니터 |

상세 도식·FACT: 정의서 05 Part A · `물리기술아키텍처_시스템표준_*`.

## A3. 용어 (설계 시 암기)

| 용어 | 설명 |
|---|---|
| Hostname | 영문 소문자+숫자 **고정 12자리**, 구분자 없음 |
| 앱 코드(4) | 대구분(2)+업무구분(2). **CMDB 사전 필수** |
| 용도(2) | WEB/WAS/AP/DB 등 논리 역할 (`wb` `ws` `ap` `db` …) |
| 순번 | 의왕 `01~49` · 안성 DR `51~99` · **`00`/`50` 금지** |
| DR 구분 | 환경 문자 변경 아님 · **순번만** (환경 통상 `o`) |
| 예외표 | FS 표준 밖 경로의 사유·승인자·만료 |

```text
 1–2 | 3–6  | 7 | 8 | 9–10 | 11–12
법인 | 앱4  |플 |환 | 용도 | 순번
 sb  | mpco | l | o |  wb  |  01
```

# Part B — 설계 절차 (How-to)

## B0. 전체 Step 맵

```text
① 대상 Host 역할·센터·환경 확정
② 12자리 조각 조립 (법인→순번)
③ CMDB·코드표·유일성 검증
④ FS: OS 마운트(B4.1) · /pgm·/aplog·/userdir·/nhod(B4.2)
⑤ 계정: 엔진/업무4자리/솔루션 표준표(B5.1) 기입
⑥ 포트: Baseline(B6.1) · OPEN(B6.2) 확정 · FW/LB
⑦ 03·인벤토리 교차 · 완료 표
```

규범·전체표(마운트·계정·포트) 원문: [`정의서 05 Part B`](../정의서/05_시스템표준_정의서.md) **§B4~B6** (가이드에 shall 표 복붙 금지).

---

## B1. Step 1 — 대상·역할·센터

| 항목 | 질문 | 기입 예 |
|---|---|---|
| 논리 역할 | WEB/WAS/AP/DB/ETL/Batch? | WEB |
| 앱 소속 | MP/RD/… (01 대구분) | MP · 업무 `co` |
| 센터 | 의왕 / 안성(DR) | 의왕 |
| 환경 | o / v / t | o (운영) |
| OS/장비 | Linux / Exadata / … | Linux → 플랫폼 `l` |

**확인 질문**: “이 Host가 DR이면 순번만 51~99이고 환경은 `o`인가?”

---

## B2. Step 2 — 12자리 조립

```text
법인(2) + 대구분(2) + 업무구분(2) + 서버(1) + 환경(1) + 용도(2) + 순번(2)
예: sb | mp | co | l | o | wb | 01  →  sbmpcolowb01
```

워크시트(설계서에 복사):

| 조각 | 값 | 근거 |
|---|---|---|
| 법인(2) | | 정의서 B3.1 |
| 대구분+업무(4) | | **CMDB** (장표 예시만으로 확정 금지) |
| 플랫폼(1) | | i/h/o/l/w/x |
| 환경(1) | | o/v/t · DR도 통상 o |
| 용도(2) | | ap/db/wb/ws/bk/bt/tl |
| 순번(2) | | 01~49 또는 51~99 |

```text
조립
  │
  ├─ 길이 ≠ 12 → 재조립
  ├─ 대문자·하이픈·점 → 제거·재작성
  └─ 표 밖 용도/법인 → ADR·표준개정 전 보류
```

## B3. Step 3 — 등록 전 검증

| # | 검사 | Pass 기준 |
|---:|---|---|
| 1 | 형식 | 12 · 소문자·숫자 · 구분자 없음 |
| 2 | 코드표 | 법인·플랫폼·환경·용도 일치 |
| 3 | CMDB | 앱 4자리 사전 등록 |
| 4 | 순번 | 01~49 또는 51~99 · 00/50 아님 |
| 5 | DR | 안성 · 환경 `o` · 순번≥51 · 개발에 51~99 금지 |
| 6 | 유일 | DNS·CMDB·IaaS·모니터·백업 |
| 7 | 역할 | 플랫폼·용도 ↔ 실제 OS/SW |

형식 1차(앱코드는 사전 대조 필수) — 정규식 원문: **정의서 §B3.8**.

## B4. Step 4 — 파일시스템 (정의서 B4.1·B4.2 채우기)

규범: [`정의서 05 §B4`](../정의서/05_시스템표준_정의서.md) — **OS 마운트 전체표·shall은 정의서만**. 여기서는 대상 Host에 대해 Y/N·경로만 기입.

### B4-a. OS 표준 마운트 (B4.1)

| Mount (정의서 B4.1) | 본 Host 적용 | 비고 |
|---|---|---|
| `/` `/boot` `/var` … | ☐ | 설치 표준과 대조 |
| `/userdir` | ☐ | **업무 계정 홈** (≠ `/home`) |
| `/home` | ☐ | 업무 서비스 계정 **금지** |
| `/<SW명>` | ☐ | WEB/WAS/보안/관제 등 |

### B4-b. AP / DB 업무 경로 (B4.2)

| 영역 | 표준 경로 | 본 Host 경로 | HA 접미·예외 |
|---|---|---|---|
| AP 프로그램 | `/pgm` | | `/pgm_<hostname>` 등 표준표 등록 ☐ |
| AP 로그 | `/aplog` | | OS `/var`와 혼재 금지 |
| 업무 홈 | `/userdir` | | B5 계정과 정합 |
| Oracle Home | `/nhod` | | **데이터 파일로 사용 금지** |
| 기타(`/sepa`…) | 정의서 B4.2 | | 임의 전용 금지 |

```text
표준 경로 밖 중요 데이터
        │
        ├─ 예외표 있음 → 만료·승인 확인
        └─ 예외표 없음 → 배치 금지 (정의서 B4.3)
```

| 할 일 | 기입 |
|---|---|
| OS 표준 FS 적용 | Y/N |
| AP/DB 3분류(`/pgm`·`/aplog`·`/userdir`·`/nhod`) | 위 표 |
| 예외 | 예외표 행(사유·승인자·만료) 또는 없음 |

## B5. Step 5 — 사용자 계정 (정의서 B5.1 채우기)

규범 계정 유형표: **정의서 §B5.1** (엔진 `apache`/`tomcat` · 업무 **앱코드 4자리** · 솔루션 `nexus`/`oracle`/…). 전체표 복붙 금지.

| 규칙 | 설계에서 할 일 |
|---|---|
| 환경 분리 | 운영/DR/개발/선도 계정 **분리** · 운영 계정 개발 재사용 금지 |
| 역할 분리 | 엔진 / 업무 / 솔루션 / 배포 |
| 로그인 | 사람=개인 계정 → 역할 전환 · 공유 서비스 계정 직접 로그인 금지(예외·승인) |
| 비밀관리 | 공용 PW · 로컬 비공식 계정 금지 |
| 업무 계정명 | Hostname 앱코드·분류와 **동일 4자리** |
| 등록 | 표준표·CMDB에만 개통 |

워크시트(정의서 B5.1 유형을 골라 행 추가):

| 환경 | 유형(엔진/업무/솔루션) | 계정 ID | 그룹 | 용도 | CMDB 등록 |
|---|---|---|---|---|---|
| o | 엔진 | apache/tomcat/… | | | ☐ |
| o | 업무(4자리) | (앱코드) | apache\|tomcat | | ☐ |
| o | 솔루션 | (정의서 B5.1) | | | ☐ |
| t | 업무 | (개발용·운영과 분리) | | | ☐ |

## B6. Step 6 — 서버 포트 (B6.1 Baseline · B6.2 OPEN)

규범: **정의서 §B6.1**(SSH 22 · Apache 80 · Tomcat 8080 · Oracle 15310/1531 · GitLab 80/443 등) · **§B6.2 OPEN**(WebTopSuite·OGG·Kafka·DataStage 등 — **수치 확정 전 상시 개통 금지**).

| 할 일 | 기준 |
|---|---|
| Baseline 조회 | 정의서 B6.1 · 현황표 등록값만 |
| OPEN 항목 | B6.2 목록 → 현황표에 **포트 수치 확정** · 충돌 검사 · FW/LB 후 할당 |
| 신규 | 행 추가 · 충돌 검사 후 할당 |
| 임시 포트 | 상시화 금지 |
| FW/LB | 포트표와 불일치 시 개통 중지 |
| 노출 | Tomcat 8080·Oracle Listener는 **승인 구간만** |

워크시트:

| No./구분 | 이름 | 포트(확정) | 출처(B6.1 / OPEN→확정) | 현황표 | FW/LB 일치 |
|---|---|---|---|---|---|
| | SSH/Apache/Tomcat/Oracle/… | | B6.1 | ☐ | ☐ |
| | (OPEN 항목명) | (미정이면 개통 금지) | B6.2 | ☐ | ☐ |

## B8. 미니 예제

```text
상호금융 마케팅 운영 WEB #01
  │
  ├─ sb + mpco + l + o + wb + 01 → sbmpcolowb01
  ├─ DR #51 → sbmpcolowb51 (환경 o 유지 · 안성)
  ├─ 개발 → sbmpcoltwb01 (순번 01 · DR 대역 아님)
  ├─ FS: / · /var · /userdir · /pgm · /aplog
  │     (업무 홈 ≠ /home · DB면 /nhod≠데이터)
  ├─ 계정: 엔진 apache · 업무 mpco(4자리) · 운영≠개발
  ├─ 포트: Baseline 80(WEB) · OPEN(Kafka 등)은 수치 확정 후
  └─ 아직 안 함: Zone 상세(02) · IF 매체(06) · Drill(11)
```

| Host | 해석 |
|---|---|
| `sbmpcolowb01` | 상호금융·마케팅·Linux·운영·WEB·의왕#01 |
| `sbmpcolowb51` | 동일 역할 **DR** #51 |
| `sbrdcoxodb01` | RDW · Exadata · 운영 DB · FS에 `/nhod` |
