## 문서 구조 (공통)

```text
Part A — Top-down 구조 이해
  §핵심 결론 · 답하는/답하지 않는 것 · ASCII 도형 · 표 · FACT/ANALYSIS
        │
        ▼
Part B — 적용 규범
  shall / must / 금지 · 체크리스트 · 관련 문서
```

## 사용 원칙

1. **충돌 시 Part B(규범) 우선** — Part A·설계가이드와 다르면 Part B를 따른다.  
2. 설계가이드는 **절차·학습용**이다.  
3. FACT와 ANALYSIS를 섞어 읽지 않는다.  
4. 상세 도식 원천은 `01-VISION`~`06-RUNTIME` 분석 MD · PPT 통합 분석.  
5. 10·11장은 PPT Gap → 본 정의서+방법론이 Baseline.  
6. 각 `… - 원본.md`는 **0.1 초안 스냅샷**(덮어쓰지 않음).
