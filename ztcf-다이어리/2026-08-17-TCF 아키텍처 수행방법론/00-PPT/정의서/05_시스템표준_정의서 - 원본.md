## 1. 목적

서버 **Hostname·파일시스템·계정·포트**의 전 환경 공통 표준을 정의한다. 임의 명명·비공식 계정/포트를 금지한다.

---

## 2. 서버 호스트 명명 (고정 12자리)

```text
hostname = 법인(2) + 대구분(2) + 업무구분(2) + 서버(1) + 환경(1) + 용도(2) + 순번(2)
         = 12자리, 영문 소문자+숫자, 구분자 없음
예: sbmpcolowb01
```

### 2.1 법인 (2)

| 코드 | 법인 |
|---|---|
| sb | 상호금융 |
| nh | 중앙회(상호금융 제외) |
| nb | 은행 |
| fg | 금융지주 |
| ag | 경제지주 |

### 2.2 애플리케이션 (4) = 대구분(2)+업무구분(2)

의미는 **중앙 애플리케이션 코드 사전(CMDB)** 을 따른다. 장표 예시(`mpco`, `rdco`)만으로 세부 확정하지 않는다.

### 2.3 서버/플랫폼 (1)

| 코드 | 의미 |
|---|---|
| i / h / o | Unix IBM / HP / Oracle |
| l | Linux |
| w | Windows |
| x | Exadata |

### 2.4 환경 (1)

| 코드 | 의미 |
|---|---|
| o | 운영 |
| v | 검증 |
| t | 개발 |

**DR은 환경 문자를 바꾸지 않고**(통상 `o` 유지) **순번 51~99**로 구분한다.

### 2.5 용도 (2)

| 코드 | 용도 |
|---|---|
| ap | AP |
| db | DB |
| wb | WEB |
| ws | WAS |
| bk | 백업 |
| bt | 배치 |
| tl | ETL |

복수 역할 시 **대표 용도** + CMDB 부가속성.

### 2.6 순번 (2)

| 대역 | 의미 |
|---|---|
| 01~49 | 주센터(의왕) |
| 51~99 | DR센터(안성) |
| 00 · 50 | **할당 금지** |

### 2.7 등록 전 검증

1. 길이 12 · 소문자 · 코드표 일치 · 앱코드 사전 대조  
2. 인벤토리 중복 없음  
3. DR이면 51~99  

---

## 3. 파일시스템

1. Linux OS 표준 FS를 기본으로 한다.  
2. AP/DB 디렉터리는 표준 **3분류**를 따른다.  
3. 예외는 예외표(사유·승인자) 없이 허용하지 않는다.

---

## 4. 사용자 계정

1. 환경(운영/DR/개발/선도)별 계정 분리. 운영 계정의 개발 재사용 금지.  
2. 역할(앱/DB/배치/배포) 분리.  
3. 공용 비밀번호·서버 로컬만의 비공식 계정 금지.

---

## 5. 서버 포트

1. 포트는 현황표에 등록된 값만 사용한다.  
2. 신규는 현황표에 행 추가·충돌 검사 후 할당한다.

---

## 6. 교차 검증

물리 목록(03)·인벤토리와 Hostname·계정·포트·FS가 **불일치하면 배포·개통하지 않는다**.
