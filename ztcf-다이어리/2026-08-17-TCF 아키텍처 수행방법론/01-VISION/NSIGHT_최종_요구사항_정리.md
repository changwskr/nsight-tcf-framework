# 농협 상호금융 NSIGHT 최종 요구사항 정리

## 1. 문서 목적

본 문서는 제공된 요구사항 화면을 기준으로 확인된 **RT-IA-0001 ~ RT-IA-0021** 요구사항을 하나의 기준 문서로 정리한 최종본이다.

정리 기준은 다음 5개 항목으로 통일한다.

- 요구사항 ID
- 요구사항명
- 요구사항 상세
- 전제조건·제약사항
- 출처

확인되지 않은 사항은 임의로 확정하지 않으며, 요구사항 화면에서 확인 가능한 범위와 기존 정리 결과를 기준으로 기술한다.

## 4. 추적성 관리 원칙

각 요구사항은 향후 다음 체계로 연결하여 관리한다.

```text
요구사항
  ↓
아키텍처 설계항목
  ↓
상세 설계 / 구성도
  ↓
서버·솔루션·애플리케이션 매핑
  ↓
테스트 / 검증
  ↓
운영 증적
```

권장 추적성 관리 항목은 다음과 같다.

| 항목 | 설명 |
|---|---|
| 요구사항 ID | RT-IA-xxxx |
| 요구사항명 | 원 요구사항 명칭 |
| 요구사항 상세 | 실제 수행해야 할 내용 |
| 전제조건·제약사항 | 적용 기준 및 제한 조건 |
| 출처 | 범위비교표, 인터뷰 등 |
| 대응 아키텍처 | Logical/Physical/Mechanism/Runtime 등 |
| 관련 산출물 | 아키텍처 정의서, 구성도, 설계서, 시험계획 등 |
| 관련 서버/시스템 | 서버 인벤토리 및 시스템 매핑 |
| 검증방법 | 설계검토, 성능시험, 장애시험, 배포시험 등 |
| 증적 | 시험결과서, 로그, 구성화면, 배포결과 등 |
| 상태 | 미착수/진행/검토/완료/보류 |

## 5. 최종 관리 기준

본 문서는 현재 요구사항 정리의 기준본으로 사용한다.

향후 요구사항 변경 또는 추가 시에는 기존 행을 임의로 덮어쓰지 않고 다음을 관리한다.

- 변경일자
- 변경사유
- 변경 전/후 내용
- 영향 아키텍처
- 영향 서버/시스템
- 영향 테스트
- 승인/검토 상태
