# 빅픽처 — 차세대 정보계 구축 방향 및 목표 아키텍처 분석

## 1. 핵심 결론

이 장표는 차세대 정보계의 상세 시스템 구성도를 보여주는 자료가 아니라, **사업 배경 → 전략 방향 → 구축 목표 → 핵심 구현 과제**를 한 장에서 연결하는 Big Picture 성격의 VISION/Strategy 장표다.

원본의 최상위 메시지는 다음과 같다.

> **고객 중심의 채널 연계와 데이터 기반 분석체계를 통해, 실시간 정보 활용과 운영 효율성을 높이는 차세대 정보계를 구축**

즉 차세대 정보계의 방향은 다음 네 축으로 요약할 수 있다.

```text
고객 중심 채널 연계
        +
고객/상품/채널 정보 통합
        +
실시간 데이터 수집·분석
        +
표준화된 운영/업무 프로세스
        ↓
차세대 정보계 구축
```

장표의 구조는 다음의 인과관계를 명확히 보여준다.

```text
구축 배경
   ↓
전략 방향
   ↓
구축 목표
   ↓
핵심 구현 과제
```

이를 다시 아키텍처 관점으로 풀면 다음과 같다.

```text
시장/고객/금융환경 변화
        ↓
채널·데이터·실시간 역량 강화
        ↓
연계 서비스 / 개인화 / 실시간 분석 기반 확보
        ↓
상담/판매 표준화
고객정보 통합
통합상품
Single View
실시간 이벤트 마케팅
실시간 DW
분석 DW
```

이 장표는 이후 마케팅플랫폼, 데이터플랫폼, BI포탈, 실시간 이벤트 처리, 인터페이스 아키텍처를 설계할 때 **왜 해당 구조가 필요한지 설명하는 상위 Architecture Rationale**로 활용할 수 있다.

# 5. 구축 배경 상세 분석

## 5.1 저성장 탈피 위한 수익모델 다변화 요구

### FACT

```text
저성장 탈피 위한 수익모델 다변화 요구
```

### ANALYSIS

이는 정보계가 단순 보고/조회 플랫폼을 넘어 다음을 지원해야 한다는 의미로 해석할 수 있다.

```text
고객 이해
   ↓
세분화
   ↓
추천 / 캠페인 / 상품제안
   ↓
수익기회 확대
```

즉 데이터와 마케팅 기능은 **비용절감 목적뿐 아니라 수익창출 수단**으로 설계되어야 한다.

---

## 5.2 디지털 고객 서비스 기대 상승

### FACT

```text
디지털 고객 서비스 기대 상승
```

### ANALYSIS

이는 다음 요구로 연결된다.

- 채널 간 일관된 정보
- 빠른 응답
- 개인화
- 비대면 서비스
- 사용자 중심 UI/UX
- 실시간 반응

즉 차세대 정보계는 내부 직원용 정보계에 머물지 않고 **디지털 고객 경험을 간접적으로 지원하는 플랫폼** 역할이 필요하다.

---

## 5.3 금융 환경 변화에 따른 경쟁 심화

### FACT

```text
금융 환경 변화에 따른 경쟁 심화
```

### ANALYSIS

경쟁 심화는 기술적으로 다음 역량을 요구한다.

```text
Change Speed
+
Data Speed
+
Decision Speed
+
Service Speed
```

즉 비즈니스 민첩성, 데이터 적시성, 빠른 채널 적용 능력이 Architecture Quality Attribute로 중요해진다.

# 6. 전략 방향 ① 채널 연계 중심 서비스 강화

## 6.1 원본 FACT

```text
채널 연계 중심 서비스 강화
```

### 의미

채널별로 별도 기능을 반복 구현하기보다, 고객과 업무 서비스를 중심으로 채널 간 정보와 기능을 연결하는 방향이다.

```text
채널 A
채널 B
채널 C
    │
    ▼
공통/연계 서비스
    │
    ▼
고객 / 상품 / 상담 / 캠페인
```

# 7. 전략 방향 ② 데이터 기반 업무 수행 체계 확립

## 7.1 원본 FACT

```text
데이터 기반 업무 수행 체계 확립
```

### ANALYSIS

업무 판단이 개인 경험이나 개별 시스템 조회에 의존하지 않고 **통합된 데이터와 분석 결과를 업무 흐름 안에서 직접 활용**하는 구조를 뜻한다.

```text
업무 수행
   │
   ├─ 고객정보
   ├─ 상품정보
   ├─ 채널정보
   ├─ 행동정보
   └─ 분석정보
          │
          ▼
    Data-driven Decision
```

# 8. 전략 방향 ③ 실시간 정보 활용 역량 강화

## 8.1 원본 FACT

```text
실시간 정보 활용 역량 강화
```

### ANALYSIS

이는 다음 세 단계가 모두 필요하다는 의미다.

```text
실시간 수집
   ↓
실시간/준실시간 처리
   ↓
실시간 활용
```

수집만 빠르고 활용이 느리면 VISION을 달성할 수 없다.

따라서 후속 설계에서는 다음 질문이 필요하다.

- 어떤 데이터가 실시간인가?
- 허용 지연은 얼마인가?
- 어느 업무에서 즉시 사용되는가?
- 실시간 데이터의 Source of Truth는 무엇인가?

# 13. 핵심 과제 ① 상담/판매 프로세스 표준화

## 13.1 원본 FACT

```text
상담/판매 프로세스 표준화

• 효율적인 고객상담 체계 구현
• 프로세스 표준화로 일관된 서비스 제공
```

### ANALYSIS

이 과제의 핵심은 단순 Workflow 통일이 아니라 **채널과 담당자에 관계없이 동일한 고객정보와 프로세스를 사용하는 것**이다.

```text
Customer
   ↓
Standard Consultation
   ↓
Product Recommendation
   ↓
Sales Process
```

### Architecture Implication

- 공통 상담 서비스
- 공통 고객 Context
- 공통 상품정보
- 공통 프로세스
- 동일 오류/결과 기준

# 37. 장표 해석 시 유의사항

이 장표는 Big Picture/Strategy 자료이므로 다음 기술을 직접 확정하지 않는다.

- 특정 DBMS
- 특정 CDC 제품
- 특정 Kafka 제품
- 특정 API Gateway
- 특정 BI 제품
- 서버/VM 사양
- 구체적인 서비스 ID
- 데이터 스키마
- 물리 네트워크

원본이 확정하는 것은 **구축의 방향과 목표, 그리고 핵심 구현 주제**다.

따라서 다음처럼 사용해야 한다.

```text
Big Picture / Vision
        ↓
Architecture Principle
        ↓
Logical Architecture
        ↓
Physical / Runtime
        ↓
Detailed Design
```

# 38. 최종 평가

이 장표는 차세대 정보계의 구축 방향을 단순 기술 현대화가 아니라 **고객·데이터·실시간·표준화의 결합**으로 정의한다.

핵심 구조는 다음과 같다.

```text
[구축 배경]
수익모델 다변화
디지털 고객 기대 상승
경쟁 심화
      ↓
[전략 방향]
채널 연계
데이터 기반 업무
실시간 활용
      ↓
[구축 목표]
채널 연계 서비스
고객 맞춤 정보
실시간 분석
      ↓
[구현 과제]
상담/판매 표준화
고객정보 통합
통합상품
Single View
실시간 이벤트 마케팅
실시간 DW
분석 DW
```

이 장표의 가장 중요한 아키텍처적 가치는 다음과 같다.

1. **비즈니스 배경과 Architecture 구현과제를 직접 연결한다.**
2. **고객·상품·채널 통합을 정보계의 핵심 기반으로 둔다.**
3. **실시간 데이터 활용을 단순 수집이 아니라 분석·마케팅까지 연결한다.**
4. **Single View와 상담/판매 표준화를 고객경험 개선 수단으로 정의한다.**
5. **실시간 DW와 분석 DW라는 이원화된 데이터 활용 기반을 요구한다.**
6. **분석 데이터는 계층별/목적별로 구조화해야 함을 명시한다.**

따라서 이 장표는 이후 상세 아키텍처에서 다음과 같이 추적되어야 한다.

```text
Business Background
       ↓
Strategy Direction
       ↓
Build Objective
       ↓
Architecture Capability
       ↓
Application / Data / Interface / Runtime Design
       ↓
KPI / NFR / Verification
```

결론적으로 이 장표는 **차세대 정보계의 고객 중심 서비스, 데이터 통합, 실시간 분석, 마케팅 실행을 하나의 목표 체계로 연결하는 핵심 Big Picture Architecture Direction**이다.
