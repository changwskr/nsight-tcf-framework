# NSIGHT 아키텍처 정의서 이미지별 분석 Markdown

## 산출물 개요

업로드된 3개 ZIP의 이미지 프레임을 각각 독립적으로 분석하여 **이미지 1장당 Markdown 1개**로 생성했다.

- `비디오 프레임 추출기 2026-08-19 8_59_10 GMT+9.zip`: **65개**
- `비디오 프레임 추출기 2026-08-19 8_57_37 GMT+9.zip`: **72개**
- `비디오 프레임 추출기 2026-08-19 8_56_31 GMT+9.zip`: **65개**
- 총 이미지: **202개**
- 총 Markdown: **202개 + README/MANIFEST**

## 분석 원칙

1. 각 Markdown은 해당 이미지에서 확인 가능한 정보만 근거로 작성했다.
2. 작은 글씨의 Hostname·수치·포트·URL은 임의 추정하지 않고 확인 필요로 남겼다.
3. 동일 장표의 연속 캡처도 사용자 요청에 따라 별도 Markdown으로 유지했다.
4. `TBD`, `New!`, 검은 화면은 설계 미완성/비내용 프레임으로 명시했다.
5. 설명은 `이미지 핵심 내용 → 아키텍처 해석 → 설계 시사점 → 확인 필요 → Evidence` 순서로 통일했다.
