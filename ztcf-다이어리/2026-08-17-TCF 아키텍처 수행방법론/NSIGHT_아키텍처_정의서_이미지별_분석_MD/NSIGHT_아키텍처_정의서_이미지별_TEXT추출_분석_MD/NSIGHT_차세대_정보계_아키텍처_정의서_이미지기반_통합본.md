# 15. 결론

본 이미지 기반 정의서에서 확인되는 NSIGHT 차세대 정보계의 핵심 구조는 다음과 같이 요약된다.

1. **서비스 영역 분리**: 마케팅플랫폼, BI포털, 데이터플랫폼, 데이터거버넌스, IT서비스/업무지원의 책임을 구분한다.
2. **데이터 역할 분리**: RDW와 ADW를 분리하고 CDC와 ETL을 목적에 맞게 사용한다.
3. **연계 방식 표준화**: 온라인·파일·데이터 인터페이스를 각각 API G/W/EAI/GSE, FOS/MFT, CDC/ETL 계열로 구분한다.
4. **애플리케이션 계층 표준화**: Controller→Service→DAO 흐름과 공통 선후처리/AOP/오류처리 규칙을 정의한다.
5. **거래 추적성 확보**: 표준전문과 GUID를 End-to-End 거래 추적의 공통 기반으로 사용한다.
6. **Physical/Runtime 분리 관리**: 운영·DR·개발·선도개발 환경을 분리하고 서버/소프트웨어 배치기준을 관리한다.
7. **DB 가용성과 자원격리**: Exadata/RAC 구조와 OLTP/배치 자원 분리로 가용성과 성능 간섭을 통제한다.
8. **개발·운영 통합 Framework**: Cloud Framework, Master Solution, CI/CD, Nexus, Batch Framework를 공통 개발·운영 기반으로 둔다.
9. **시스템 표준화**: Hostname, 파일시스템, OS계정, 서비스 포트 기준을 통일한다.
10. **미완성 영역의 명시적 관리**: Self-BI, 단말 프레임워크, 모니터링, 확장성, 백업은 현재 이미지 버전에서 OPEN 상태로 유지한다.

이 문서는 **추출 이미지가 실제로 뒷받침하는 범위의 통합 Architecture Baseline**이며, `OPEN` 항목은 별도 원본 또는 후속 설계자료 확보 후 확정해야 한다.
