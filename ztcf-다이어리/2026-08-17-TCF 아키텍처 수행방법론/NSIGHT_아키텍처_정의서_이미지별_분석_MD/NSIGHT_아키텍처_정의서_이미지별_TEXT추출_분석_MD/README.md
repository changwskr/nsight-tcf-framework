# NSIGHT 아키텍처 정의서 이미지별 TEXT 추출·분석본

이 디렉터리는 3개 프레임 ZIP의 **202개 이미지 각각**에 대해 다음을 수행한 수정본입니다.

1. 이미지의 텍스트를 줄 단위로 추출
2. 그림/구성도/표의 시각적 배치를 **Markdown TEXT 표**로 재구성
3. 주요 아키텍처 구성요소를 별도 TEXT 표로 정리
4. 이미지별 핵심 내용·아키텍처 분석·설계 시사점 작성
5. OCR 신뢰도가 낮은 줄을 별도로 표시하여 임의 보정을 방지

각 그룹의 `markdown/`에는 원본 이미지 번호와 1:1로 대응하는 Markdown이 들어 있습니다. 원본 프레임은 사용자가 올린 3개 ZIP을 기준으로 대조합니다.
