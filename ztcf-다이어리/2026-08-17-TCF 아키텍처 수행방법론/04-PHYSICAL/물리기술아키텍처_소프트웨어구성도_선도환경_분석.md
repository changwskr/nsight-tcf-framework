# 물리기술아키텍처 — 소프트웨어 구성도 — 선도환경 분석

> 원본 범위: `3. 물리 기술 아키텍처 > 3.2 소프트웨어 구성도`  
> 원본 장표: 77쪽, 선도개발 소프트웨어 구성도  
> 분석 원칙: 장표의 노드·소프트웨어·OS와 주석을 우선 기록하며, 장표에 없는 BI포탈 세부 배치와 AS-IS DB 사양은 임의 확정하지 않는다.

---

## 1. 핵심 결론

선도환경은 마케팅플랫폼과 단말 개발·배포 체계, 형상·라이브러리 관리, CRM DB를 최소 단위로 구성한 **선행 개발·검증 환경**이다.

- 모든 애플리케이션 노드는 `#1` 단일 구성이다.
- 마케팅플랫폼 WEB/WAS가 선도 업무 실행 계층을 구성한다.
- 단말관리·단말배포·단말개발도구가 UI 개발부터 배포까지의 경로를 제공한다.
- 소스관리 AP는 `GitLab Runner + GitLab`, 라이브러리 노드는 `NEXUS`를 사용한다.
- 마스터솔루션은 공통 프레임워크, WEB, WAS를 한 노드에 적재한다.
- CRM DB는 `DB Safer + DBMS`의 UNIX 기반 AS-IS 장비다.
- 장표 주석상 선도 장비는 마케팅 영역부터 BI포탈까지 포함하지만 BI포탈의 개별 소프트웨어 노드는 그림에 표시되지 않는다.

```text
선도 개발 범위
  ├─ 마케팅플랫폼 WEB/WAS
  ├─ 단말관리·배포·개발도구
  ├─ GitLab·Runner·NEXUS
  ├─ 마스터솔루션
  └─ CRM DB(AS-IS)
```

## 4. 마케팅플랫폼 세로 목록

### 4.1 마케팅플랫폼 WEB `#1`

```text
[마케팅플랫폼 WEB]
        ↓
       WEB
        ↓
  Default S/W
        ↓
 Linux (RHEL9)
```

- 역할: 선도 마케팅 업무의 WEB 접점과 WAS 라우팅
- 단일 노드이므로 HA 검증보다 기능·연계 패턴 검증에 초점이 있다.

### 4.2 마케팅플랫폼 WAS `#1`

```text
[마케팅플랫폼 WAS]
        ↓
    실시간 EBM
        ↓
   캠페인정보 적재
        ↓
       WAS
        ↓
  Default S/W
        ↓
 Linux (RHEL9)
```

- 역할: 실시간 이벤트 기반 마케팅과 캠페인 데이터 적재 업무 수행
- 장표의 캠페인 적재 명칭은 세부 제품이나 인터페이스명이 아니라 기능 표기로 해석한다.

### 4.3 BI포탈 포함 주석 해석

```text
선도 장비 범위
마케팅 영역 ────────────────── BI포탈 영역
```

장표에는 BI포탈 WEB/WAS 노드가 별도로 그려지지 않았다. 따라서 다음 가능성을 확인해야 한다.

1. 마케팅플랫폼 WEB/WAS에 BI포탈 기능을 함께 배치
2. 물리 장비 범위에는 포함하지만 본 장표에서 논리 노드를 생략
3. 다른 공용 또는 기존 BI포탈을 연계 사용

BI포탈 포함 여부는 배포목록, VM 명세, 포트·도메인 목록으로 확정해야 한다.

## 8. CRM DB 세로 목록

### 8.1 CRM DB `#1` — AS-IS 장비

```text
[CRM DB]
        ↓
    DB Safer
        ↓
       DBMS
        ↓
  Default S/W
        ↓
       UNIX
```

- 역할: 선도 마케팅·단말 검증에 필요한 CRM 업무 데이터 제공
- `DB Safer`: DB 접근통제 또는 보안 계층으로 해석된다.
- `AS-IS 장비`: 신규 IaaS/Appliance가 아닌 기존 물리 또는 기존 운영 장비 재사용을 의미한다.
- 위험: 노후 OS·DBMS, 지원 종료, 개발·운영 데이터 혼재, 단일 노드 장애 가능성
- 확인사항: 데이터 마스킹, 접근계정 분리, 백업, 용량, 패치, 폐기 또는 전환 계획


## 12. 개발환경 대비 차이

| 관점 | 선도환경 | 개발환경 | 분석 |

| 위험 | 영향 | 대응 방향 |
|---|---|---|

| Default S/W 불명확 | 보안·백업·관제 누락 | 실제 Agent·제품·정책 명세화 |

- [ ] 선도 검증 결과를 개발·운영환경에 확산하는 승인 기준이 있는가?

## 15. 최종 평가

선도환경은 마케팅과 단말 업무를 중심으로 공통 프레임워크 및 DevOps 공급망을 조기에 검증하는 최소 구성이다. 기능 검증과 표준화에는 효율적이지만 모든 노드가 단일 구성이고 CRM DB가 AS-IS 장비이므로, 가용성·성능·운영 동등성을 입증하는 환경으로 사용하기에는 한계가 있다.

핵심 관리 포인트는 **BI포탈 실제 포함 범위 확정, GitLab–Runner–NEXUS 공급망 추적, 단말 도구 버전 호환성, AS-IS CRM DB의 보안·지원수명 관리**다.
