# Wave 6 Submission Templates

이 폴더의 JSON은 모두 **Draft**이다. 생성만으로 승인되지 않는다.

1. 필요한 파일을 복사해 값을 채운다.
2. 승인자/날짜/Evidence Ref를 실제 값으로 기록한다.
3. Runtime은 실제 Production Runtime 결과만 `PASS + PRODUCTION_RUNTIME + runtime_approved=true`로 기록한다.
4. 작성 완료된 파일만 `98BQ-evidence-inbox/` 아래 동일 분류 폴더로 복사한다.
5. Wave 5 Intake/Re-Gate Tool을 실행한다.
