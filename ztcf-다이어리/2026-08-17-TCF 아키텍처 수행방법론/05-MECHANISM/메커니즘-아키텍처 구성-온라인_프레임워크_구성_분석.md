## 1. 한 줄 요약

**NH Cloud Framework**는 **Controller(다형 진입) → FWK LIB(시스템 선·후) → AOP(업무 선·후) → Service·DTO·DAO·O-R Mapper** 로 온라인 거래를 처리하고, **Config·Library·동적 Config Handler** 로 운영 설정을 관리한다. **Master Solution**(파라미터) · **CI/CD(Jenkins/GitLab/NEXUS)** · **STS IDE(Plug-In)** 가 개발·배포·운영을 **런타임과 동형**으로 지원한다.

## 3. NH Cloud Framework TEXT 표그림

### 3.1 런타임 계층 (상→하)

| 계층 | 구성요소 | 역할 (장표) |
|---|---|---|
| **진입** | **Controller** | 요청 유형별 라우팅 |
| **시스템 횡단** | **FWK LIB** | **시스템 선 처리** · **시스템 후 처리** |
| **업무 횡단** | **AOP** | **업무 선처리** · **업무 후처리** (업무 선 처리·업무 후 처리) |
| **업무** | **SERVICE** | `Service (Biz)` — Biz Logic |
| **데이터** | **DTO** | getter/setter — 입·출력 |
| **영속** | **DAO** | Data 변환 · **Mapper Call** |
| **ORM** | **O-R Mapper** | **Query Mapping** · **Query Execute** |

### 3.2 Controller 다형 진입점

| Controller | 용도 (장표) |
|---|---|
| **Nhins** | 화면(Screen) 거래 |

### 3.3 Config · Library · 동적 설정

| 구분 | 항목 | 비고 |

## 5. PDMG/TCF · Runtime 매핑

장표 **NH Cloud Framework**와 PDMG **`pdmg-fw`** 구현의 **개념 대응**이다. (NH Cloud = 상품명 · PDMG = 프로젝트 Baseline)

| 장표 구성 | PDMG/TCF 대응 | 비고 |
|---|---|---|
| **Nh** (기본 Controller) | `OnlineTransactionController` | `POST /{serviceId}` |
| Nhins/NhFile/NhRD/NhInbound/NhSSO | *(별도 Controller)* | PDMG는 **온라인 JSON** 중심 — 유형별 분리 **Gap** |
| **FWK LIB** · 시스템 선·후 | `DefaultFilter` · `ServicePreventionInterceptor` · `stf`/`etf` · ResponseBodyAdvice | [거래_처리_구조](./거래_처리_구조_분석.md) ①⑧ |
| **AOP** · 업무 선·후 | Spring AOP · Handler/Facade 훅 (선택) | 85631/37·38 상세 |
| **SERVICE** | `TransactionHandler` → Facade → **Service** | |
| **DTO** | `*DTOin/out` · `hdr_nhnis`+`dto` | |
| **DAO · O-R Mapper** | DAO + `resource/*-ORA.xml` | [패키지_계층](./온라인_프레임워크_패키지_계층_분석.md) |
| **Library** · SSO/암호화/Log | `pdmg-fw:commons` (JWT, ImageLog, MDC) + `tcf` | |
| **API G/W** | CruzAPIM 연계 Adapter | [전문_표준화](./전문_표준화_분석.md) |
| **동적 Config · Master** | Master Solution (85631/42·43) | PDMG 로컬은 `application.yml` 중심 |
| **CI/CD** | Jenkins/GitLab/NEXUS | Infra 표준 — 앱 코드 외부 |

```text
[PDMG TCF — NH Cloud Framework 대응 실행선]

Client (pdmg-ui / JSON)
  → DefaultFilter / Interceptor     ← FWK LIB (시스템 선)
  → OnlineTransactionController     ← Nh
  → TcfFacade (stf → Dispatcher → Handler → Service → DAO)
  → etf / ResponseBodyAdvice        ← FWK LIB (시스템 후)
  → Client

  (선택) AOP/업무 훅               ← AOP 업무 선·후
  (연계) CruzAPIM Adapter          ← API G/W
```

> **Gap**: 장표 **Controller 6종(Nhins/File/RD/Inbound/SSO/Nh)** 과 PDMG **단일 OnlineTransactionController** — 파일·RD·Inbound·SSO 전용 진입은 **별도 모듈 또는 미구현**. **MIDAS·XDataSet·동적 Config Handler**는 NH Cloud 제품 영역.

### 8.2.1 진입계: Client · Controller

#### C01 — Client (전용 단말)

| 항목 | 내용 |
|---|---|
| **장표 역할** | 온라인 거래 **발의·수신** 주체. Request → Framework → Response |
| **프로토콜** | json/http 표준전문 ([전문_표준화](./전문_표준화_분석.md)) · GUID 최초 설정 ([GUID_관리](./GUID_관리_체계_분석.md) R2) |
| **Charset** | UTF-8 ([캐릭터셋](./캐릭터셋_정의_분석.md)) |
| **PDMG 대응** | `pdmg-ui` · WebTopSuit · 정보단말 — `hdr_nhnis`+`dto` POST |
| **연결** | → Controller(Nh*) · ← 표준 응답 전문 |
| **Gap** | Package UI·비표준 경로는 별도 Client 규격 |

#### C02 — Nhins Controller (화면)

| 항목 | 내용 |

| **책임** | HTTP 수신 · 서비스ID 인식 · FWK/AOP 선·후처리 위임 · Service 호출 |
| **연결** | Client → FWK LIB → AOP → SERVICE |
| **PDMG 대응** | `OnlineTransactionController` — `POST /{serviceId}` (개념 동일) |
| **하위 Evidence** | [단말_어플리케이션_프레임워크_연계_분석](./단말_어플리케이션_프레임워크_연계_분석.md) (85631/32) |

#### C03 — NhFile Controller (파일)

| 항목 | 내용 |
|---|---|
| **장표 역할** | **파일 Upload/Download** 전용 진입 |

### 8.3 컴포넌트 의존 관계 (요약)

```text
                    ┌──────── Master Solution ────────┐
                    │         (동적 Config)            │
                    └──────────────┬──────────────────┘
                                   ▼
Client ──► Controller ──► FWK LIB ──► AOP ──► SERVICE ──► DAO ──► O-R Mapper ──► DB
              │              │                              │
              │              └─ Config/Library ◄────────────┤
              ├── NhFile ────────────────────────────────► FOS
              └── (Service) ─────────────────────────────► CruzAPIM

STS IDE + Plug-In ──► GitLab ──► Jenkins ──► NEXUS ──► 배포 ──► WAS(Framework)
```

| 의존 | 규칙 |
|---|---|
| Controller → FWK LIB | **필수** — 모든 진입점 공통 |
| FWK LIB → AOP | AOP는 **선택** — 업무 선·후 필요 시 |
| SERVICE → DAO | DB 거래 **필수** · CruzAPIM은 **선택** 연계 |
| Config → 전 계층 | 정적 yml + 동적 Master |
| Library → FWK/AOP/Service | 횡단 기능 **주입** |
