이 파일의 최초 스냅샷은 [`README - 원본.md`](./README%20-%20원본.md)에 있습니다. 이후 편집은 본 파일만 합니다.

## 쓰는 규칙

| 구분 | 규칙 |
|------|------|
| 폴더명 | `YYYY-MM-DD-주제` (같은 날 여러 주제면 폴더를 나눔) |
| 원본 스캔 | `원본/`, `원본 JPG/`, `원본 PDF/` |
| 마크다운 보완 | 기존 MD를 고치기 전에 `{문서명} - 원본.md` 스냅샷을 남김 |
| FACT / ANALYSIS | 원문에서 읽힌 것(`FACT`)과 해석(`ANALYSIS`)을 섞지 않음 |
| `copy` 폴더 | 작업 중 복제본. 본편을 우선한다 |
