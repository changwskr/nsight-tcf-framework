## 핵심 포인트

- **개발환경**은 언어(Java/Python/JS/HTML5) → 형상(Bitbucket/GitLab EE) → CI/CD(Jenkins, GitLab Runner, Spinnaker, ArgoCD) → 레지스트리(Nexus/Harbor + 각 CSP) → 테스트/품질 → Jira 계열로 이어짐
- **실행환경**은 WAS/WEB(국산 JEUS·WebToB 포함) → Open API(하나금융티아이 ONE API) → Service Mesh → DBMS/NoSQL/DW → 컨테이너(K8s) → OS → 로그 → MQ/Cache
- CSP 관리형 서비스는 대체로 **Cloud = public**, 자체 구축 OSS는 **컨테이너 ○ + Cloud ○**
- CentOS EOS, Docker Desktop 유료화, Oracle RAC(OCI 외 제약), Java LTS/EOA가 비고에 명시됨
- 동일 제품이 역할별로 중복 수록됨 (Redis: NoSQL + Cache, ELK: 응용로그 + 통합로그, Apigee: Management + Gateway, Whatap/Dynatrace: 인프라 + APM)
