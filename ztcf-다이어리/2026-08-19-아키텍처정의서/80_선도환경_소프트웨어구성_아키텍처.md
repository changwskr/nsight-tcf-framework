# 4. 선도환경의 특징

1. 운영/개발 전체 구성보다 훨씬 축소된 경량 환경이다.
2. 업무 서비스는 마케팅플랫폼 WEB/WAS를 중심으로 구성한다.
3. 단말관리/단말배포/개발도구/소스관리 체계는 포함한다.
4. 마스터솔루션과 Nexus는 테크시스템부 영역으로 별도 표시된다.
5. DB는 신규 Appliance가 아니라 AS-IS CRM DB를 활용하는 것으로 장표에 명시되어 있다.
6. 장표 주석상 선도장비의 적용범위는 마케팅영역에서 BI포탈까지 포함한다고 설명되어 있으나, 개별 BI포탈 서버는 본 장표에 별도 노드로 표현되어 있지 않다.

# 5. 확인 필요 사항

| 항목 | 확인 |
|---|---|
| BI포탈 | 주석상 포함과 실제 서버 미표시의 의미 |
| CRM DB | AS-IS 장비의 DBMS/버전/수명주기 |
| WebTop/EdgeSquare | 차세대 최종 표준과의 관계 |
| Master Solution | NH Cloud Framework 전환 시 역할 |
| Default S/W | 실제 보안/백업/시스템 SW 제품목록 |
