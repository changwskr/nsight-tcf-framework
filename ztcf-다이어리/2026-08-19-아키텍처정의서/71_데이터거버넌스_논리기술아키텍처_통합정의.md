# 데이터거버넌스 논리 기술 아키텍처 통합 정의
## 이미지 기반 TEXT 아키텍처 · 전체 컴포넌트 표 · 연계 흐름 통합

> 원본 위치: `2. 논리 기술 아키텍처 > 2.4 논리 기술 아키텍처 정의`  
> 원본 페이지: `68`  
> 기준 이미지: `22(1).png`  
> 목적: 데이터거버넌스 논리 기술 아키텍처를 **텍스트 구조도로 재구성**하고, 비즈메타·데이터품질·데이터흐름·RDW/ADW·IT메타·대내/대외 연계·개발/운영지원 구성까지 하나의 표 체계로 통합한다.  
> 작성 원칙: 이미지에 표시된 명칭과 연결관계를 우선한다. 화살표 방향이 불명확한 선은 `연계`로 표현하고, 이미지에 없는 제품 버전·물리 서버 수량·세부 DB 스키마는 임의로 추가하지 않는다.

# 1. 전체 아키텍처 개요

데이터거버넌스 논리 기술 아키텍처는 다음 7개 축으로 구성된다.

1. **사용자 채널 및 접근영역**
2. **비즈메타 관리**
3. **데이터 품질 관리**
4. **데이터 흐름 관리**
5. **RDW/ADW 데이터플랫폼 연계**
6. **IT 메타 및 대내·대외 시스템 연계**
7. **개발·배포·운영 지원**

# 8. RDW/ADW 연계 구조

이미지에서 데이터거버넌스는 RDW와 ADW에 직접 연결되며, RDW와 ADW 사이에는 ETL이 존재한다.

```text
데이터거버넌스
       │
      JDBC
       ▼
      RDW
       │
      ETL
       ▼
      ADW
       ▲
       │
   JDBC/연계
       │
데이터거버넌스
```

| 구분 | 방식 | 대상 | 의미 |
|---|---|---|---|
| 거버넌스 ↔ RDW | JDBC | RDW | 메타/품질/흐름 관련 데이터 조회 또는 관리 연계 |
| RDW → ADW | ETL | ADW | 운영/실시간 데이터를 분석영역으로 변환·적재 |
| 거버넌스 ↔ ADW | JDBC/연계 | ADW | 분석영역 메타·품질·흐름 연계 |

> 이미지상 개별 선의 정확한 호출 방향은 일부 불명확하므로, 본 문서에서는 `연계`로 표현한다.

# 17. 아키텍처 핵심 특성

## 17.1 메타·품질·흐름을 하나의 거버넌스 플랫폼으로 통합

본 구조는 데이터거버넌스를 단순 메타관리로 한정하지 않고 다음 세 축으로 구성한다.

```text
Business Metadata
+
Data Quality
+
Data Lineage / Flow
```

즉, **데이터의 의미·품질·흐름을 하나의 관리체계로 통합**하는 구조다.

## 17.2 RDW/ADW와 직접 연결

거버넌스가 별도의 문서관리 시스템으로 존재하는 것이 아니라 실제 데이터 저장소인 `RDW`, `ADW`와 JDBC 기반으로 연결되어 있다.

## 17.3 데이터 흐름 관리가 독립 애플리케이션 영역

`흐름 수집/파싱`과 `흐름 분석/검색`이 별도 WAS 영역으로 표현되어 있어 데이터 Lineage/Impact Analysis 기능을 핵심 거버넌스 영역으로 본다.

## 17.4 품질 관리가 규칙 기반

데이터 품질은 단순 통계뿐 아니라 다음을 포함한다.

```text
CTQ
DQI
Profiling
Business Rule(BR)
```

따라서 **지표 + 프로파일 + 업무규칙**을 결합한 품질관리 모델이다.

## 17.5 IT 메타와 비즈메타의 연결 기반

이미지에서는 `IT 메타`가 별도 FOS 연계 대상으로 표현되고, 중앙에는 `비즈메타`가 존재한다.

이는 향후 다음 구조로 확장 가능한 형태다.

```text
업무 용어/표준
      ↕
비즈메타
      ↕
IT 메타
      ↕
DB / Table / Column / Interface / Application
```

단, 이 구체적인 매핑 구조 자체는 이미지에 직접 명시된 것은 아니므로 상세 규칙은 별도 정의가 필요하다.

# 18. 이전 노드 기술 컴포넌트와 통합 매핑

앞서 기술 컴포넌트 장표에서 확인한 데이터거버넌스 노드와 연결하면 다음처럼 정리할 수 있다.

| 논리 노드 | 주요 기능 | 기술 컴포넌트 | Runtime/Infra |
|---|---|---|---|
| 비즈메타/데이터품질 WAS | Business Service | eCAMS Agent, 배치자동화 Agent, JDBC Driver, APM Agent, Java Framework Engine, WAS | JVM → OS → VM → Cloud |
| 데이터 흐름 WAS | Business Service | eCAMS Agent, 배치자동화 Agent, JDBC Driver, APM Agent, Java Framework Engine, WAS | JVM → OS → VM → Cloud |
| RDW | Real-time DW | OGG, DBSafer, DBMS | OS → DB 전용 Appliance |
| ADW | Analytical DW | DBSafer, DBMS | OS → DB 전용 Appliance |
| IT 메타 연계 | Metadata | FOS | 대내 연계 영역 |

5. **대내/대외 연계를 APIM·EAI·FOS·MFT·MCA로 표준화**
