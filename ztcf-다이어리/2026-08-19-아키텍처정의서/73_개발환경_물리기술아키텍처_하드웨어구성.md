# 2. 마케팅

| 구분 | 노드 | 번호 | Hostname |
|---|---|---:|---|
| WEB | 마케팅플랫폼 WEB | #1 | `sbmpcoltwb01` |
| WAS | 마케팅플랫폼 WAS | #1 | `sbmpcoltws01` |
| AP | 실시간처리 AP | #1 | `sbmpepltap01` |
| AP | 행동정보처리 AP | #1 | `sbmpbpltap01` |
| AP | 고객행동데이터 AP | #1 | `sbmpbdltap01` |

> **이미지 주석:** `미니싱글뷰 WEB, WAS는 마케팅플랫폼 WEB, WAS 서버에 통합 구성`

즉 개발환경에서는 미니싱글뷰 전용 WEB/WAS를 별도 노드로 두지 않고 마케팅플랫폼 WEB/WAS와 통합한다.

```text
마케팅플랫폼 WEB #1 ─┐
                     ├─ 마케팅 + 미니싱글뷰 통합
마케팅플랫폼 WAS #1 ─┘

실시간처리 AP #1
행동정보처리 AP #1
고객행동데이터 AP #1
```

# 5. 원천 데이터 이행 영역 / 임시

이미지 우측에는 점선으로 별도 임시 영역이 표시되어 있다.

| 구분 | 노드 | 번호 | Hostname |
|---|---|---:|---|
| 임시 AP | SQL품질/이행 AP | #1 | `sbimsltap01`로 판독 |

```text
[원천 데이터 이행 영역/임시]
          │
          └─ SQL품질/이행 AP #1
```

이는 개발환경에서 데이터 이행·품질 검증용 임시 자원을 별도 논리 영역으로 둔 것으로 해석된다.

# 6. 저장소 / DB

| 구분 | 구성 | 번호 | Hostname |
|---|---|---:|---|
| Storage | 정보계 스토리지 | - | - |
| DB Appliance | ADW/RDW DB Appliance | #1,#2 | `sbrdcoxtdb01-02` |

운영환경에서 ADW와 RDW DB Appliance를 별도 노드군으로 구성한 것과 달리 개발환경은 **ADW/RDW 통합 DB Appliance #1,#2** 형태다.

```text
개발
 └─ ADW/RDW DB Appliance #1,#2

운영
 ├─ ADW DB Appliance #1~#6
 └─ RDW DB Appliance #1,#2
```
