# 3. 개발환경 핵심 스택

```text
실시간처리 AP
  Spring Boot
  JDK
  Linux RHEL9

행동정보처리 AP
  Spring Boot
  JDK
  Linux RHEL9

고객행동데이터 AP
  Kafka(KRaft)
  JDK
  Linux RHEL9
```

개발환경 장표는 운영 장표보다 기술제품명을 더 구체적으로 드러내고 있다. 특히 실시간/행동처리에 `Spring Boot`, 고객행동데이터에 `Kafka(KRaft)`가 명시된다.

# 5. 개발환경 특징

1. 대부분 1노드 단일 구성이다.
2. 실시간처리/행동정보처리는 Spring Boot + JDK로 명시된다.
3. 고객행동데이터 AP는 Kafka KRaft 기반이다.
4. 데이터 DB는 개발용 RDW/ADW Appliance #1,#2로 통합되어 있다.
5. GitLab/GitLab Runner가 소스관리 노드에 배치된다.
6. SQL Canvas/Open POP 기반의 SQL품질/이행 임시 서버가 존재한다.
7. Nexus 라이브러리는 테크시스템부 영역으로 분리된다.
