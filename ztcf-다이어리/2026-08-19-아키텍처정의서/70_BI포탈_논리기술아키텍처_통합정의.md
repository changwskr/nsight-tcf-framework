# BI 포탈 논리 기술 아키텍처 통합 정의
## 이미지 기반 TEXT 아키텍처 · 전체 컴포넌트 표 · 연계 흐름 통합

> 원본 위치: `2. 논리 기술 아키텍처 > 2.4 논리 기술 아키텍처 정의`  
> 원본 페이지: `67`  
> 기준 이미지: `21(1).png`  
> 목적: BI 포탈 논리 기술 아키텍처를 **텍스트 구조도로 재구성**하고, 채널·신용실적·BI포탈·대시보드·Self-BI·OLAP·RDW/ADW·배치/ETL·데이터거버넌스·대내외 연계 컴포넌트를 하나의 표 체계로 통합한다.  
> 작성 원칙: 이미지에 표시된 명칭과 연결을 우선한다. 화살표 방향이 불명확한 선은 단순 `연계`로 표현하며, 원본에 없는 물리 구성/버전/벤더 설정은 임의로 추가하지 않는다.

# 1. 전체 아키텍처 개요

BI 포탈 논리 기술 아키텍처는 다음 영역으로 구성된다.

1. **정보계/패키지 단말 채널**
2. **HTTP → L4 → WEB 접근구간**
3. **신용실적 애플리케이션**
4. **BI포탈 애플리케이션(Data Eye)**
5. **대시보드 애플리케이션**
6. **Self-BI 애플리케이션(BI-Matrix)**
7. **OLAP 애플리케이션(MSTR)**
8. **Application Framework / WAS / VM / IaaS**
9. **배치 AP / ETL**
10. **RDW / ADW**
11. **계정계 / BCV / 경영정보 연계**
12. **IT 메타 / 비즈메타 / 데이터 품질**
13. **대내 시스템 / 대외 시스템 연계**
14. **GitLab / Git Runner / eCAMS / Nexus / FWK Manager**

# 21. 핵심 아키텍처 특성

## 21.1 BI 기능을 역할별로 분리

BI 영역은 단일 솔루션이 아니라 다음 역할별 애플리케이션 조합으로 구성된다.

```text
신용실적
+
BI포탈(Data Eye)
+
대시보드
+
Self-BI(BI-Matrix)
+
OLAP(MSTR)
```

각 기능을 포탈 하나에 집중시키지 않고, 사용 목적별 솔루션/애플리케이션으로 분리한 구조다.

## 21.2 RDW와 ADW를 동시에 활용

```text
업무/실시간 조회 → RDW
분석/마트 조회   → ADW
RDW → ETL → ADW
```

BI포탈은 RDW와 ADW를 모두 데이터 소스로 활용하는 구조로 표현되어 있다.

## 21.3 온라인 BI와 배치/ETL이 분리

- 사용자는 `HTTP → L4 → WEB → BI Application`
- 데이터 적재는 `Batch AP / ETL / Control-M`
- 조회는 `JDBC / RDW / ADW`

으로 역할이 나뉜다.

## 21.4 BI와 데이터거버넌스가 연결

`IT 메타`, `비즈메타`, `데이터 품질`이 별도 컴포넌트로 표현되어 있어 BI 사용자 분석환경이 메타/품질체계와 연계되는 구조다.

# 22. 최종 통합 정의

```text
정보계/패키지 단말
       ↓ HTTP
       L4
       ↓
      WEB
       ↓
┌────────────────────────────────────────┐
│                BI 포탈                 │
│                                        │
│ 신용실적                               │
│ BI포탈(Data Eye)                       │
│ 대시보드(경영/거버넌스)                │
│ Self-BI(BI-Matrix)                     │
│ OLAP(MSTR)                             │
│                                        │
│ Application Framework / WAS            │
│ VM / IaaS                              │
└────────────────────────────────────────┘
        │
        ├─ JDBC ─► RDW
        │            │
        │           ETL
        │            ▼
        └──────────► ADW
                     │
        ┌────────────┼──────────────┐
        ▼            ▼              ▼
     경영정보      대내 시스템      대외 시스템

배치 AP / ETL
      ▲
      │
  Control-M

마케팅정보
   ├─ CDC → CDC중계 → 계정계
   └─ MFT/ETL → ADW

IT메타 / 비즈메타 / 데이터품질
   └─ FOS 연계
```

BI 포탈 아키텍처의 핵심은 다음 다섯 가지다.

1. **신용실적 + Data Eye + Dashboard + Self-BI + OLAP의 역할 분리**
2. **RDW와 ADW를 동시에 활용하는 이중 데이터 허브 구조**
3. **ETL/배치와 온라인 BI 서비스 분리**
4. **메타데이터/데이터품질과 BI 서비스 연계**
5. **APIM/EAI/FOS/MFT/MCA를 통한 대내외 통합**
