# 어플리케이션 도메인 구성 정의

차세대 정보계의 어플리케이션 도메인을 데이터플랫폼, BI 포탈, 마케팅플랫폼, 데이터거버넌스, IT서비스 및 업무지원, 빅데이터플랫폼 영역으로 구분하여 정의한다.

---

## 전체 도메인 구성

| 대분류 | 주요 영역 | 상태 표기 |
|---|---|---|
| 데이터플랫폼 RDW | SOR, 통합/요약/집계, 보고서 마트, Feed Back | 신규 |
| 데이터플랫폼 ADW | SOR, 통합/요약/집계, 보고서 마트, 단위업무 마트, Feed Back, 분석 지원 | 고도화 |
| BI 포탈 | BI 포탈, 신용 실적, OLAP, Self-BI, 대시보드 | 신규 / 고도화 |
| 마케팅플랫폼 | 마케팅 공통, 고객 정보, 고객 상담, 이벤트, 마케팅 지원, 고객 접촉 | 신규 / 고도화 |
| 데이터거버넌스 | 비즈메타, 데이터 흐름, 데이터 품질 | 신규 |
| IT서비스 및 업무지원 | 형상관리, 데이터 처리, 보고서 디자이너, 프레임워크 관리, 라이브러리, 정보단말관리, 배치관리, 실시간 중계, 시스템 공통 | 신규 |
| 빅데이터플랫폼 | 데이터 처리/저장, 데이터 분석, 데이터 관리 | 대응계획 |
