# 3. 공통 소프트웨어 스택 분류

## 3.1 WEB 계층

```text
[WEB 노드]
업무 WEB
  ↓
WEB / WebTop / EdgeSquare
  ↓
Default S/W
  ↓
Linux RHEL9
```

주요 WEB 계층 유형은 다음과 같다.

- 일반 업무 WEB: `WEB`
- 단말관리 WEB: `WebTop Manager + WebTop`
- 단말배포 WEB: `EdgeSquare`
- BI/Self-BI/신용실적 WEB: 각 업무 WEB 컴포넌트

---

## 3.2 WAS/AP 계층

```text
[업무 서비스]
        ↓
업무 WAS / AP
        ↓
Spring Batch / DBMS Client / Control-M 등
        ↓
Default S/W
        ↓
Linux RHEL9
```

---

## 3.3 DB / Appliance 계층

```text
RDW / ADW / CDC
       ↓
OGG (해당 노드)
DB Safer
DBMS
Default S/W
       ↓
Linux 또는 UNIX
```

# 4. 운영환경 특징

1. WEB/WAS는 대부분 2노드 이상으로 운영된다.
2. 단말관리/단말배포는 일반 업무보다 더 많은 노드(#1~#4, #1~#6)를 사용한다.
3. ADW는 #1~#6, RDW는 #1,#2의 Appliance 구성이다.
4. CDC중계 DB는 UNIX 기반으로 표시되어 일반 Linux 업무서버와 구분된다.
5. 데이터 이행은 임시 변환/이행/SQL품질/추출 노드가 별도 구성된다.
6. 배치는 Spring Batch + Petra Cipher + Oracle Client + Control-M 조합이다.
7. 마스터솔루션은 테크시스템부 영역으로 분리되어 있다.

# 5. 아키텍처 관점 체크포인트

| 항목 | 확인사항 |
|---|---|
| Default S/W | 시스템 S/W/보안/백업/OS백업의 실제 제품명 |
| WEB/WAS | 현재 Apache/Tomcat 표준으로 대체/변경 여부 |
| WebTop | 현재 운영에서 유지되는지 확인 |
| EdgeSquare | 단말배포 체계의 현재 사용여부 |
| OGG | RDW와 CDC중계 DB 역할 중복/연계 관계 |
| DB Safer | DB 접근통제 범위 |
| 데이터 이행 | 임시 노드의 폐기/존치 시점 |
| Control-M | 배치 및 ETL 스케줄링 책임범위 |
