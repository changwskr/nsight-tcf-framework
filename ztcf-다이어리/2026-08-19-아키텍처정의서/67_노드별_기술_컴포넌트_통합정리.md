# 노드별 기술 컴포넌트 정의
## 이미지 기반 통합 정리 · 공통/마케팅/데이터/BI/거버넌스/IT지원/기타

> 원본 범위: `2. 논리 기술 아키텍처 > 2.3 기술 컴포넌트 정의`  
> 원본 페이지: `51 ~ 64`  
> 분석 대상 이미지: 공통 기술 컴포넌트, 마케팅플랫폼(1/3~3/3), 데이터플랫폼, BI포탈(1/4~4/4), 데이터거버넌스, IT서비스 및 업무지원(1/3~3/3), 기타 기술 컴포넌트  
> 정리 기준: 이미지에 표시된 **노드 → 업무/솔루션 → 미들웨어/Agent/Driver → JVM → 시스템 공통영역 → OS/VM/Cloud 또는 Appliance/Bare Metal** 순으로 전사하였다.  
> 주의: 제품/솔루션 명칭은 원본 표기를 유지하며, 원본에 없는 버전/벤더/설정값은 임의 보완하지 않는다.

---

# 1. 전체 개요

이미지에서 식별되는 기술 노드는 다음과 같이 구성된다.

| 영역 | 노드 수 | 주요 노드 |
|---|---:|---|
| 마케팅플랫폼 | 9 | 마케팅 WEB/WAS/DB, 미니싱글뷰 WEB/WAS/DB, 행동정보처리 AP, 실시간처리 AP, 고객행동데이터 AP |
| 데이터플랫폼 | 2 | RDW, ADW |
| BI포탈 | 12 | BI포탈 3, 신용실적 3, OLAP 3, Self-BI 3 |
| 데이터거버넌스 | 2 | 비즈메타/데이터품질 WAS, 데이터흐름 WAS |
| IT서비스 및 업무지원 | 9 | 단말관리 3, 단말배포/배치 3, CDC/ETL/출력물 3 |
| 기타 기술 컴포넌트 | 3 | 데이터이행 서버, 데이터변환 서버, 데이터추출 서버 |
| **합계** | **37** | 이미지상 논리 기술 노드 |

# 2. 공통 기술 컴포넌트

## 2.1 VM 기반 구성 공통 구조

```text
┌──────────────────────────────┐
│            솔루션            │  ← 솔루션 영역
├──────────────────────────────┤

│ 백업 관리     │ 인프라 통합관제│

├──────────────────────────────┤
│              OS              │
├──────────────────────────────┤
│              VM              │
├──────────────────────────────┤
│            Cloud             │
└──────────────────────────────┘
```

# 13. 아키텍처 해석

## 13.1 애플리케이션 노드는 대부분 VM/Cloud 기반

WEB/WAS/AP의 대부분은 다음 공통 기반을 사용한다.

```text
Application
  ↓
JVM
  ↓
OS
  ↓
VM
  ↓
Cloud
```

따라서 이미지의 논리 기술 아키텍처는 애플리케이션 계층을 **JVM 기반 VM 실행모델**로 표준화한 구조로 볼 수 있다.

---

## 13.2 데이터 노드는 Appliance 중심

RDW/ADW 및 여러 논리 DB는 다음 구조다.

```text
Business Data
  ↓
DB Security
  ↓
DBMS
  ↓
OS
  ↓
DB Dedicated Appliance
```

즉 애플리케이션은 VM/Cloud 기반이고 주요 데이터베이스는 DB 전용 Appliance 기반으로 분리되어 있다.

---

## 13.3 일부 데이터처리는 Bare Metal 사용

다음 노드는 VM/Cloud가 아니라 Bare Metal이다.

| 노드 | OS | Infra |
|---|---|---|
| CDC 중계 DB | UNIX | Bare Metal |
| 데이터변환 적재 ETL | Linux | Bare Metal |

이는 이미지상 고정된 기술 배치이며, 별도 성능/솔루션 제약 여부는 이 장표만으로 확정할 수 없다.

---

## 13.4 모니터링/운영 Agent의 표준화

다수 노드에서 반복되는 요소:

- eCAMS Agent
- APM Agent
- 배치자동화 Agent

이들은 업무 기능 자체가 아니라 **운영/관측/배치 자동화 공통 기술**로 사용된다.

# 15. 최종 요약

이번 이미지군에서 기술 아키텍처는 크게 다음 6개 층으로 볼 수 있다.

```text
1. 업무/솔루션
   Business Service / Web Service / OLAP / Self-BI / Stream / ETL / RD ...
           ↓
2. 운영·연계 Agent
   eCAMS / Batch Agent / APM / JDBC / ODBC
           ↓
3. 실행 기술
   Web Server / Web Application Server / Java Framework / Kafka / DBMS
           ↓
4. Runtime
   JVM
           ↓
5. 공통 시스템 영역
   백신 / 계정 / 보안 / 개인정보 / 백업 / 통합관제 / 모니터링 / 운영관리
           ↓
6. 인프라
   OS → VM → Cloud
   또는
   OS → DB 전용 Appliance
   또는
   UNIX/Linux → Bare Metal
```

핵심적으로 **WEB/WAS/AP는 JVM + VM + Cloud**, **DB는 DB 전용 Appliance**, **CDC/ETL 일부는 Bare Metal**이라는 3가지 배치모델로 정리할 수 있다.
