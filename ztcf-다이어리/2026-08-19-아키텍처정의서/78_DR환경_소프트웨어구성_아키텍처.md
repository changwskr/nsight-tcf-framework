# 3. DR 범위 해석

DR 이미지에서 명시적으로 복구 대상이 되는 영역은 다음과 같다.

```text
서비스 제공
 ├─ 마케팅 WEB/WAS
 └─ 미니싱글뷰 WEB/WAS

운영지원
 ├─ 단말관리 WEB/WAS
 ├─ 단말배포 WEB/WAS
 └─ 마스터솔루션

데이터
 └─ RDW Appliance + OGG
```

반면 운영환경에 존재하지만 DR 이미지에 표시되지 않은 구성은 다음과 같다.

- 실시간처리 AP
- 행동정보처리 AP
- 고객행동데이터 AP
- BI포탈
- 신용실적
- Self-BI
- 비즈메타/데이터품질
- 데이터흐름관리
- 배치
- ETL
- CDC중계 DB
- ADW
- UNO Dashboard

따라서 DR 환경은 운영환경 전체 복제형이 아니라 **선택적 핵심 서비스 복구형**으로 표현된다.

# 4. DR 핵심 체크포인트

| 항목 | 확인 필요 |
|---|---|
| OGG | RDW의 DR 복제 역할과 Data Guard와의 관계 |
| ADW | DR 미배치가 실제 정책인지 장표 생략인지 |
| BI | DR 서비스 대상 여부 |
| 실시간 AP | DR 시 재기동/대체 전략 |
| 단말관리/배포 | DR 전환 시 배포/운영 기능 필요성 |
| 마스터솔루션 | DR 서버 #51의 활성화 절차 |
