## 본문

전문 변경 프로세스는 비즈니스 변경에 따라 전문 변경이 필요할 때, 변경 프로세스를 통해 전문 변경 이력 관리를 체계적으로 수행함.

| 단계 | 역할 | 비고 |
|------|------|------|
| 2.1 전문 변경 요청 | 업무개발 | 전문 변경 요청서 |
| 2.2 전문 내용 검토 | 통합 관리 | 코어뱅킹·채널·단위시스템·기타 입력 |
| 2.3 전문 변경 영향도 검토 | 통합 관리 | 전문 변경 검토 결과서 |
| 2.4 전문 변경 설계 | 통합 관리 | 변경=Yes |
| 2.5 전문 변경 설계 결과 검토 | 통합 관리 | |
| 2.6 전문 변경 승인 요청 | 통합 관리 | 검토 결과서 + 변경 전문 정의서 |
| 2.7 전문 변경 승인 | 승인자 | |
| 2.8 전문 변경 설계 반영 | 통합 관리 | |
| 2.9 전문 변경 통지 및 전파 | 통합 관리 | |
| 2.10 결과 수보 및 반영 | 업무개발 | |

승인자: 전행 변경 프로세스 관리자(ITSM 체계)에게도 검토·승인을 득함.
