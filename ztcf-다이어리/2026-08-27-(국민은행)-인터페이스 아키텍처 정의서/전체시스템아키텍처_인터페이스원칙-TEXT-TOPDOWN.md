# 1. L0 — 한 문장 / 충돌 순위

## 1.1 한 문장

```text
채널 거래  = Host 에서 원장 확정
정보 소비  = SIS ODS · EDW 경유
채널-업무  = MCI
```

```text
확정은 Host, 운영은 ODS, 분석은 EDW, 도메인간 EAI, 채널은 MCI
```

# 2. L1 — 목적별 경로 6종

```text
목적
 │
 ├─[거래] 원장 확정
 │    Channel/Satellite ──MCI──► Host
 │    대외기관          ──EAI──► Host / 외환전산망
 │
 ├─[복제] 운영 허브
 │    Host / 위성원장   ──CDC/EAI──► SIS ODS
 │
 ├─[분석] 웨어하우스
 │    SIS ODS           ──ETL/EAI──► EDW
 │
 ├─[계량] 리스크
 │    원장·포지션       ──EAI/파일──► RDM/ALM
 │    RDM/ALM           ──EAI Async──► SIS 경영정보
 │
 ├─[소비] 조회만
 │    EDW / SIS         ──EAI──► CRM / EIS
 │
 └─[행정] 주경로 밖
      지식정보          ──EAI──► Host / SIS
```

금지 대각선:

```text
Channel ──X──► SIS/EDW   원장확정
CRM/EIS ──X──► Host      update
SIS ODS ──X──► Host      커밋 대기
내장RMS ──X──► RDM       동일 장애도메인 IF
지식정보──X──► 수신/여신  주경로
```

# 4. L3 — IF-P01 ~ P04

## 4.1 IF-P01 원장 확정은 Host에서 끝낸다

```text
[권고]
Channel / Satellite
        │ MCI
        ▼
      Host 커밋     ← 여기서 거래 완료
        │ CDC/EAI  (이후, Async)
        ▼
     SIS ODS

[금지]
Channel ────X────► SIS 원장 write
Channel ────X────► EDW 원장 write
Host 커밋 ──X────  ODS 적재 성공을 전제로
```

---

## 4.2 IF-P02 채널은 MCI, 도메인 간은 EAI

```text
직원채널 · 비대면 · IC
        │ 원칙 2
        ▼
       MCI ──────────────► Host
        │
파일은 MFT (본거래와 분리)

Host · SIS · EDW · CRM · 지식정보 · RDM
        │ 원칙 1
        ▼
    대내/대외 EAI

[금지]
Channel ──EAI만──► Host 원장 우회
도메인 간 DB-LINK / 공유폴더 / 임시 FTP  상시
```

구간:

```text
IB/전자금융/IC  → Host              MCI
대외망/외환채널 → Host·외환전산망   대외 EAI
Host            → SIS               CDC 또는 EAI
지식정보        ↔ Host/SIS          EAI
RMS/ALM         ↔ SIS               EAI
```

---

## 4.3 IF-P03 상품·Hub → 타는 Async

```text
Host OLTP thread
        │
        │  커밋
        ▼
      완료
        │
        X 기다리지 않음
        │
        ▼ Async
   CRM / EDW / 성과 / 원가 / 경영정보

[금지]
Host 스레드 ──sync wait──► EDW
Host 스레드 ──sync wait──► CRM
Host 스레드 ──sync wait──► 성과관리

예외 E3  제한적 Sync = 승인 후에만. 기본값 아님
```

---

## 4.4 IF-P04 운영 복제 ≠ 분석 적재

```text
Host / 위성원장
        │
        │  소량·구조변환     EAI
        │  대량 실시간       CDC
        │  준실시간          EAI Deferred
        ▼
   ┌─────────┐
   │ SIS ODS │  운영 조회 1차 소스
   └────┬────┘
        │  ETL / EAI
        ▼
   ┌─────────┐
   │   EDW   │  ODS Image · 로그 · 성과 · 원가
   └─────────┘

[금지]
ODS + EDW  한 JDBC로 동시 write
EDW 배치를 Host OLTP 자원에서 실행
당일 영업 조회를 EDW Image로 대체
```

# 5. L4 — IF-P05 ~ P08

## 5.1 IF-P05 위성은 별도 ODS 슬롯

```text
신용카드 ──► ODS[카드]
증권투신 ──► ODS[해당 슬롯]
방카     ──► ODS[해당 슬롯]
자산운용 ──► ODS[해당 슬롯]

[금지]
카드원장 ──섞음──► Host 수신 테이블 ──► ODS
```

대고객 카드 거래 자체는 위성 원장 경로. ODS로 가는 것은 **데이터 IF**.

---

## 5.2 IF-P06 CRM/EIS는 소비만

```text
        조회
EDW/SIS ──EAI Async──► CRM (SFA · CRM분석)
EDW/SIS ──EAI      ──► EIS (임원정보 · HIS)

원장 변경 필요 시
        │
        ▼
   새 Host 거래 (MCI)

[금지]
SFA ──UPDATE──► Host
EIS 화면 ──트리거──► ODS 적재 Job
```

---

## 5.3 IF-P07 Dual RMS — 운영 ≠ 계량

```text
Host 여신 + 담보관리
        │ EAI 운영
        ▼
  SIS 내장 RMS     심사 · 사후 · 건전성 · 금감원

원장 · 포지션
        │ EAI/파일
        ▼
  RDM / ALM        시장·신용·운영 · BIS · 내부모형
        │ EAI Async
        ▼
  SIS 경영정보     환류

[금지]
심사 온라인 ──wait──► RDM 엔진 완료
내장 RMS + RDM  =  하나의 Interface ID
```

---

## 5.4 IF-P08 지식정보는 원장 주경로 밖

```text
지식정보
  인사 · 감사 · 오피스 · EDMS · 자금
        │ EAI
        ├────────► Host   (조직 · 권한)
        └────────► SIS    (예산 · 평가)

원장 주경로
  Channel ──MCI──► Host 수신/여신
        │
        X  지식정보 끼우지 않음

[금지]
자점감사 ──직접 read──► Host 원장 테이블 (상시)
포털 세션 ──MCI──► 원장 거래
```

# 6. L5 — IF-P09 ~ P12

## 6.1 IF-P09 본거래 MCI, 파일 MFT

```text

        │
        ├──────── 본거래(원장) ──MCI──► Host
        │
        └──────── 파일 전송    ──MFT──► 파일저장

                                      ▼ Completion Signal

[금지]
대용량 파일 ──MCI 전문 본문──► Host
```

# 8. L7 — 시나리오 / 체크 / 한 장

## 8.1 시나리오 TEXT

```text
S1 수신 거래
   IB ──MCI──► Host 수신 커밋 ──CDC/EAI Async──► ODS[수신] ──ETL──► EDW

S2 여신 심사
   Host 여신+담보 ──EAI──► 내장 RMS
   (RDM은 별 경로, wait 금지)

S3 카드
   카드위성 ──CDC/EAI──► ODS[카드] ──ETL──► EDW ──EAI──► CRM
   (Host 수신 테이블 경유 금지)

S4 성과·원가
   ODS + SIS 경비예산 ──► 경영정보 ──ETL──► EDW 성과/원가 ──EAI──► EIS

S5 리스크
   포지션 ──EAI──► RDM/ALM ──Async──► SIS 경영정보

S6 행정
   인사/감사 ──EAI──► Host 조직 · SIS 평가     (원장 주경로 밖)

S7 파일 포함 채널
   본거래 ──MCI──► Host
   파일   ──MFT──► 저장 ──Signal──► 소비
```

## 8.2 개통 체크 TEXT

```text
개통 전 전부 YES. 하나라도 NO 이면 개통 안 함.

[ ] 소스 = Channel/Host/위성/SIS/EDW/RMS/지식정보/CRM·EIS 중 하나
[ ] 목적 = 원장확정/운영복제/분석적재/계량/소비/행정 중 하나
[ ] 표준표 No.1~14 선택
[ ] P01  확정이 Host에서 끝나는가
[ ] P02  채널이면 MCI / 도메인 간이면 EAI
[ ] P03  Host→정보계면 Async
[ ] P04  ODS 매체와 EDW 매체를 안 섞었는가
[ ] P06  CRM이 Host를 안 쓰는가
[ ] P07  내장 RMS와 RDM을 한 ID로 안 묶었는가
[ ] P09  파일이면 MFT + Completion Signal
[ ] P11  Tx ID / Batch ID가 계약에 있는가
```
