## 본문

**우측 상단:** III. 환경 별 시스템 구성방안 / 2. 운영시스템

운영환경은, 채널이 Client로서 Connection 기반으로 일반 거래 처리를 요청하는 세션 관리와, MCI가 Client로서 Connectionless 기반으로 BID 거래 처리를 요청하는 세션 관리 방안의 검토가 필요함

**소제목:** 운영 인프라 환경 구성방안 - 세션 관리

### 방안 설명

**1. 메인 거래 관련 세션 처리**
- 최초 채널 전송 시 세션을 1회 연결하여 유지하고 종료 시 세션 단절
- MCI가 tcp 통신의 Server로서, 채널은 Client로서 동작
- 동기방식의 경우 채널(client)은 요청전문 전송 후 응답 대기하며, 비동기 방식은 전문 전송 후 응답 대기 없음
- 채널의 동기/비동기 방식과 무관하게 MCI와 Back-End 시스템은 동기방식 처리

**2. BID 거래 관련 세션 처리**
- 이체처리 결과를 송신하거나, 비로그인 상태 및 로그인 상태의 고객 행태를 감지하여 즉각-Offering과 알림 정보를 MCI에서 채널로 일방적으로 송신할 때 사용
- Bid 거래 전송 후 세션을 단절하는 Connectionless 방식의 세션 관리
