# 전행 표준전문 관리 R&R

> 원본: `원본/CamScanner 2026. 08. 27. 19.36_44.pdf`  
> 문서: KB국민은행 · Enterprise Interface Architecture 정의서 · 원문 전사(FACT)

## 본문

전행 표준 전문 및 적용을 위해 전문구조 정의, 전문 상세내용 정의, 인터페이스 기술구조, 메시지 변환 모듈 및 Adapter를 제공하고 가이드 할 역할 정의가 필요함.

| 구분 | 설명 | 수행 주체 |
|------|------|-----------|
| 채널 표준 전문 | 전문 형식 정의, 메시지 구조 설계·관리. 내부 항목 정의. 항목별 속성·자리수·기록 방법 가이드 | MCI, EAI |
| 내부 표준 전문 | 전문 형식 정의, 메시지 구조 설계·관리. 헤더부·공통부 내부 항목 정의. 항목별 가이드 | 어플리케이션 아키텍처 |
| 개별부 구조·가이드 | 개별부 입/출력 유형별 구조 정의. 채널부·내부 표준 전문 간 메시지 설계 가이드 | AA, MCI, EAI |
| 전행 통합로그 전문 | 전문 형식 정의, 메시지 구조 설계·관리. 내부 항목·속성 가이드 | 어플리케이션 아키텍처 |
| 전문 인터페이스 기술 구조 | 노드 간 인터페이스 기술 표준. Global UID. 프로토콜, 전문 길이, 정보교환 표준코드, 한글코드 등 | AA, TA |
| 메시지 변환 모듈 및 가이드 | Mapper(필드 매핑·변환), Parser(템플릿·룰 기반 분석·추출). 템플릿 등록·화면 작성 가이드. Adaptor 제공 | MCI, EAI |

※ 외부기관 외부전문 ↔ 내부표준전문 변환은 대외EAI(또는 대외MCI)에서 수행함.
