**6. 시스템 간 인터페이스 기준**

채널을 경유하는 거래는 MCI, 채널 이외의 대내외 시스템 간 연계는 EAI 인터페이스를 원칙으로 하며<sup>1)</sup> EDW로의 데이터 연계 인터페이스는 EAI와 함께 CDC, ETL을 활용함

### 인터페이스 구간 유형 별 기준

**① 대내 도메인 간 및 대외 기관과의 인터페이스는 EAI 사용을 원칙으로 함**
- 시스템 도메인(계) 내 : 시스템간 인터페이스는 EAI를 사용함
- 파일 전송 거래는 MFT(Managed File Transfer) 경유하되, EAI를 통한 통합 전송 내역관리
- ※ 예외 Case 는 추후 별도 정의하여 관리

**② 채널은 업무 시스템과 MCI 경유 인터페이스를 원칙으로 함**
- 거래가 파일을 포함하는 경우 본 거래는 MCI 경유, 파일 전송 거래는 MFT(Managed File Transfer)로 직접 전송
- 옴니채널 연계 서비스 지원을 위한 거래 조합, 분할은 MCI가 수행함

**③ RDW로의 원천 데이터 연계는 CDC, ETL, EAI 솔루션 사용**
- 소량의 실시간 데이터 또는 원천과 타겟의 구조가 다른 경우 EAI 활용
- 상품처리, 마케팅 플랫폼으로부터의 대량 실시간 데이터 복제는 CDC 활용
- EDW와 단위 시스템 간의 인터페이스는 ETL, EAI 사용
- 준 실시간 요건은 EAI Deferred 배치 인터페이스를 통한 연계 활용

1) 기술검증을 통해 전행 채널, 대내외 인터페이스 솔루션 아키텍처 방향성 최종 결정 예정
