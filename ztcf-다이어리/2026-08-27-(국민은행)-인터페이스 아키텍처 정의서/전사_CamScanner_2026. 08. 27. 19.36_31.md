# 대내 채널 통합(MCI) 유형별 처리 원칙 — 특화 기능

## 본문

**위치:** IV. 인터페이스 처리방안 → 3. 인터페이스 유형별 처리 원칙

MCI는 Web Admin 환경에서 전문 I/O 매핑·등록, 채널 거래 전문 처리, 거래 검증, 인증/권한 관리 등 특화 기능을 제공함.

| # | 기능 | 설명 |
|---|------|------|
| 1 | 전문 매핑 등록환경 제공 | 채널별 전문 유형·I/O를 정의하기 위한 채널 전문 I/O 매핑 등록 환경 |
| 2 | 채널 전문 처리 | 채널 거래 처리 시 채널 전문의 생성·송신·결과관리 |
| 3 | 전문 처리 공통 기능 제공 | 채널 공통 거래 검증 및 인증/권한. 거래처리 로그 기반 정합성·검증 |
