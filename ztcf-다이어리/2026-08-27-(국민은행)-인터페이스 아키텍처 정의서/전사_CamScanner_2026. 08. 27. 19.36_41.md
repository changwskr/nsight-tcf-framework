# 대내 EAI 유형별 처리 원칙 — 주요 기능

> 원본: `원본/CamScanner 2026. 08. 27. 19.36_41.pdf`  
> 문서: KB국민은행 · Enterprise Interface Architecture 정의서 · 원문 전사(FACT)

## 본문

대내 EAI는 전문변환, 전문로깅, 서비스 관리, 전문 관리 등을 주요 기능으로 제공.

| # | 기능 | 설명 |
|---|------|------|
| 1 | 전문 변환 | 소스 시스템의 다양한 메시지 형식을 타겟 시스템에 적합한 메시지 또는 프로토콜로 전환 |
| 2 | 전문 로깅 | 거래 추적, 통계, 리포팅, 인터페이스 현황 실시간 모니터링. 성능 부하 최소화 |
| 3 | 서비스 관리 | 서비스 요청부터 종료까지 라이프사이클 전반 관리 |
| 4 | 전문 관리 | 전문 생성, 전문 분기, Rule 관리, 로깅, 에러 처리, 정합성 체크 |
| 5 | 트랜잭션 관리 | 트랜잭션 시작부터 종료까지 트랜잭션 관리자에 등록·관리 |
| 6 | Common Manager | 사용자 관리, 로그 분석, 시뮬레이션, 집계/조회 관리 공통 모듈 |
| 7 | Common Business | 결번처리, 일일대사, 재처리, Timeout, 암복호화, 에러 처리, 사용자 관리, 로그 관리 등 |
| 8 | 모니터링 및 관리 | 송수신·장애·통계·유실 정보. 전문·프로세스·트랜잭션·서비스 전반 모니터링 |

- 원문 페이지: 33
