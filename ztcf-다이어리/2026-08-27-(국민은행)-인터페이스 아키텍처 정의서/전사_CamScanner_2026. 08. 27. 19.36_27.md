**탭:** 상세원칙 및 지침(선택) · 유형별 상세원칙 · 전행 표준전문

**표시:** Back up

채널 - 업무시스템 구간은 MCI, 단위시스템(인터넷뱅킹 - 마케팅플랫폼) 구간은 EAI, 상품서비스계 - 데이터 Hub 구간은 CDC 등을 적용하여 인터페이스 구성함

**소제목:** 인터페이스 지침 적용 사례

### 인터페이스 정의
- **1 채널 - MCI - 상품서비스계**  
  채널에서 상품서비스계의 다양한 서비스를 이용하기 위한 Transaction Path
- **2 채널 - MCI - 마케팅 Hub계**  
  채널에서 마케팅 Hub계의 다양한 서비스를 이용하기 위한 Transaction Path
- **3 업무시스템 - EAI - 업무시스템**  
  업무시스템에서 타 시스템으로 전문 및 파일을 전송하기 위한 Transaction Path
- **A 인뱅/스뱅 - 클릭스트림 AP**  
  인뱅/스뱅 사용자의 마우스 클릭 정보와 터치 정보를 전달하기 위한 Transaction Path
- **C 상품서비스 - 실시간 분석**  
  실시간 분석 서버로 데이터의 실시간 복제를 위한 Transaction Path
- **D 마케팅플랫폼 - 실시간 분석**  
  DB Direct Access Path

### 범례
- 실선 양방향 화살표: MCI 거래
- 점선 양방향 화살표: EAI 거래
- **[A]** Agent 기반 데이터 송신
- **[C]** CDC 기반 데이터 송신
- **[D]** DB Access
