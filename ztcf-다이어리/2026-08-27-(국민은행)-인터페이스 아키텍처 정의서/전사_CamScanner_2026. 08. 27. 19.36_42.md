# 전행 표준전문 관리 Life Cycle — 생성 프로세스

## 본문

**위치:** IV. 인터페이스 처리방안 → 4. 표준전문

표준전문 관리절차 및 프로세스 수립을 통해 전행 차원의 표준전문 및 인터페이스를 관리하고, 개발 담당자와 전문관리 담당자들의 업무 효율성을 높임.

| 단계 | 역할 | 산출물 |
|------|------|--------|
| 1.1 전문 생성 요청 | 업무개발 담당자 | 전문 정의서 작성 |
| 1.2 전문 수행 계획 수립 | 전행 인터페이스 통합 관리 담당자 | 전문 적용 계획서 |
| 1.3 전문 수행 계획 승인 | 승인자 | |
| 1.4 신규 전문 정의 설계 | 통합 관리 담당자 | |
| 1.5 신규 전문 검토 회의 | 통합 관리 담당자 | |
| 1.6 신규 전문 정의 보고 | 통합 관리 담당자 | 신규 전문 정의서 |
| 1.7 신규 전문 정의 승인 | 승인자 | |
| 1.8 신규 전문 통지 및 전파 | 통합 관리 담당자 | |
| 1.9 전문 요청 결과 수보 및 반영 | 업무개발 담당자 | |

- **업무개발 담당자:** To-Be 통합 표준 전문관리 시스템 내 전문 양식으로 생성 요청
- **인터페이스 통합 관리 담당자:** 신청 검토, 신규 전문 정의 설계·보고·승인 요청, 통지·전파
- **승인자:** 전행 표준 전문 기준으로 계획·정의를 검토/승인
