## 1. 한눈에 보기

**TCF ON + `nhnis.fw.timeout.enabled=true`** 이면 온라인 거래는 Worker Pool에서 실행되고,  
요청 Thread는 `Future.get(remaining)`으로 대기한다. 시간 초과 시:

1. `ActiveJdbcStatementRegistry.cancelAll` → **`Statement.cancel()`**
2. `future.cancel(true)` → Worker interrupt
3. `OnlineTimeoutException` → HTTP **504** / `FW_TIMEOUT`
4. Worker 측 TX는 rollback (시작됐을 때만)

```text
요청 Thread
  TcfFacade
    ExecutionDeadline 바인딩
    OnlineTimeoutExecutor.execute
      │
      ├─ Worker submit (pdmg-online-*)
      │     bind(evidenceKey)
      │     TransactionTemplate (ServiceId별 Policy)
      │       Dispatcher → Handler → Facade → Service → DAO
      │       MyBatis: queryTimeout + TrackingStatement 등록
      │
      ├─ (remaining < 1s) deadline 시각에 cancelAll 예약
      │
      └─ Future.get(remainingMs)
            Timeout → cancelAll + future.cancel(true)
                 → OnlineTimeoutException → 504
```

| 계층 | 역할 | 한계 |
|---|---|---|
| `Future.get` | 클라이언트에 시간초과 확정 | Worker/SQL을 자동 종료하지 않음 |
| `future.cancel(true)` | Worker interrupt | JDBC가 interrupt를 무시할 수 있음 |
| `setQueryTimeout` | JDBC 초 단위 safety | remaining &lt; 1s 구간은 과다할 수 있음 |
| **`Statement.cancel()`** | 등록된 활성 Statement 강제 취소 | DB/드라이버별 best-effort |
| sub-second scheduler | 1초 floor 보완 | Statement가 Registry에 있어야 함 |

## 2. 설정 (현행)

```yaml
nhnis:
  fw:
    tcf:
      enabled: true
    timeout:
      enabled: true
      milliseconds: 5000
      overrides:
        mgcoa5530S0: 10000
      pool-size: 20
      queue-capacity: 100
      min-start-budget-ms: 1000
      sql-safety-timeout-seconds: 10
    transaction:
      default-manager: rdwTransactionManager
      default-mode: RDW_READ_WRITE
      services:
        mgcoa5530S0:
          mode: RDW_READ_ONLY
```

| 키 | 의미 |
|---|---|
| `milliseconds` | 기본 제한(ms). serviceId override 없으면 이 값 |
| `overrides.<serviceId>` | 거래별 제한(ms) |
| `min-start-budget-ms` | Worker가 TX를 열기 전 최소 남은 시간. 미달 시 즉시 Timeout |
| `sql-safety-timeout-seconds` | Deadline 미바인딩 시 MyBatis safety ceiling(초) |
| `pool-size` / `queue-capacity` | Worker Pool. 포화 시 503 `FW_OVERLOADED` |
| `transaction.services.*.mode` | 최외곽 TX readOnly 등 Policy (`RDW_READ_ONLY` 등) |

`enabled=false`(또는 미설정) → `SyncOnlineTimeoutExecutor` (동기, 본 Executor 제한 없음).  
이 경우 최외곽 TX는 Facade `@Transactional`이 담당한다.

## 3. Worker · 트랜잭션 · 참여

| 층 | Timeout ON | Timeout OFF |
|---|---|---|
| 실행 Thread | `pdmg-online-*` Worker | 요청 Thread |
| 최외곽 Physical TX | Worker `TransactionTemplate` | Facade `@Transactional` |
| Facade `@Transactional(REQUIRED)` | **참여** | **BEGIN** |
| Context/MDC | `OnlineTimeoutWorkerContext`로 전파 | 요청 Thread 그대로 |

조회 거래의 `readOnly`는 **최외곽 Policy**(`nhnis.fw.transaction.services`)에 반영한다.  
이미 열린 TX에 참여하는 Facade의 `readOnly=true`만으로는 물리 TX 속성이 바뀌지 않을 수 있다.

## 4. JDBC Statement.cancel 경로

```text
MyBatis prepare
  → TrackingStatement (Statement/Prepared/Callable)
  → ActiveJdbcStatementRegistry.register

Timeout / sub-second deadline
  → cancelAll(evidenceKey)
  → Statement.cancel()
  → 로그 [ONLINE-TIMEOUT][JDBC-CANCEL] cancelInvoked=N

Statement.close / Worker unbind
  → unregister / clear
```

검증:

- 단위: `JdbcStatementCancelExampleTest` (Raw cancel + Executor 경로)
- 라이브: `--nhnis.demo.mgcoa5530-jdbc-hold-ms=15000` → `cancelInvoked=1`

데모 sleep(`Thread.sleep`)만으로는 Statement가 등록되지 않아 `cancelInvoked=0`일 수 있다.  
이는 설계상 정상이며, JDBC hold 데모로 cancel 경로를 검증한다.

## 5. 오류 · 응답

| 예외 | HTTP | `stdErrCode` |
|---|---|---|
| `OnlineTimeoutException` | 504 | `FW_TIMEOUT` |
| `OnlineOverloadException` | 503 | `FW_OVERLOADED` |

`TcfFacade`는 `OnlineTimeoutException`이면 **etf 재처리를 건너뛴다** (동일 예외 이중 발생 방지).

## 6. 범위 / 보장 / 비보장

**범위 안:** TcfFacade → Dispatcher → Handler → Facade → Service → DAO (Timeout ON Worker TX 안)

**범위 밖:** DefaultFilter, 시스템 선·후처리, ImageLog, ResponseBodyAdvice wall-clock kill

**보장:**

- 적용 timeoutMs 내 미완료 시 클라이언트 504
- TX가 시작된 경우 늦은 커밋 방지(rollbackOnly / cancel)
- 등록된 JDBC Statement에 cancel 시도 + Worker interrupt

**비보장 / best-effort:**

- 모든 DB/드라이버에서 cancel이 즉시 SQL을 끊는 것 (Oracle 등 환경별 재확인)
- Filter~Advice 전체 구간의 단일 wall-clock kill
- UI `AbortController`가 서버 Worker를 직접 죽이는 것 (별개)
