3장을 집필하라.

기존 집필 규칙을 모두 적용한다.

집필 전에:

- 1장
- 2장
- SOURCE-MAP 3장
- BOOK-TOC 3장과 4장
- 관련 기본자료
- -1 재분석자료
- 다이어그램
- 실제 패키지 구조

를 확인하라.

3장의 목적은
2장에서 하나의 실행 Flow로 보았던 PDMG를
이번에는 Layer와 Component 책임 관점으로 분해하여 설명하는 것이다.

중심 질문은 다음이다.

- Framework는 무엇을 담당하는가
- Entry는 무엇을 담당하는가
- Application은 무엇을 담당하는가
- Rule은 왜 분리되는가
- DTO는 어느 경계에 존재하는가
- Persistence는 무엇만 해야 하는가
- Client는 어디에 위치하는가
- 의존 방향은 어디까지 허용되는가
- 역방향 의존이 왜 문제인가
- 현재 구조와 목표 구조의 차이는 무엇인가

단순 레이어 정의가 아니라
실제 PDMG 클래스가 어느 레이어에 속하고
서로 어떻게 호출되는지를 사례와 함께 설명하라.

작성 후 품질검사를 실행하고 스스로 보강하라.
