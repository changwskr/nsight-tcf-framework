# 제24장. JWT 인증 전체 구조 — ASCII 확장본 상세목차

> **목차 작성 기준**
>
> 2026-08 PDMG 책 기준자료를 현재 우선 기준으로 사용한다. 2026-06~07 별도 `tcf-*` Java Source는 Package/Service ID가 다른 별도 스냅샷으로서 교차검증·TO-BE 참고에만 사용한다.
>
> **핵심 PDMG 판정**
> - `/jwt/admin/login.html` → `/online` + `mgjwa1000C0` 로그인
> - `PasswordEncoder.matches()`와 활성 사용자 확인
> - Access 15분 / Refresh 8시간
> - Access RS256, RSA 2048 기동생성, `kid=nsight-jwt-rs256`
> - `/.well-known/jwks.json` Public Key 공개
> - Refresh opaque random + DB SHA-256 Hash + Rotation
> - Logout Access Denylist + Refresh revoke
> - SSO Issue는 Internal HMAC/Timestamp/Service/IP 신뢰호출
> - 현재 PDMG는 RS256 발급 ↔ HMAC `jwt.secret` 업무 검증 불일치
> - 일반 업무 UI Authorization Bearer 미첨부 Gap
> - `type=ACCESS` Claim은 Source 충돌로 current PDMG Java 재검증 필요
> - 기동시 Key 생성/고정 kid는 restart/scale-out/rotation 위험
> - permitAll 관리 API와 parse-only revoke는 보완대상
