# 제30장. 환경설정에서 소스까지 추적하기 — ASCII 확장본 상세목차

> **중심 추적 공식**
>
> `Key → 정의/Override → Final Environment → Consumer → Bean → Caller → Thread/TX/Context → HTTP/DB/Security → Runtime Evidence → Test → Rollback`
>
> **Source 교정**
> - TCF OFF는 항상 Facade/TX가 아니다. 실제 Controller callee와 첫 Spring TX Proxy를 확인한다.
> - TCF ON+Timeout ON outer TX는 Worker `TransactionTemplate`이다.
> - `jwt.enabled`는 current Filter switch가 아니다.
> - `jwk-set-uri`는 current 업무 HMAC verifier consumer에 연결되지 않는다.
> - `application-fw-defaults.yml`은 current 자동 PropertySource 근거가 없다.
> - `exceptionCode.yml` import와 실제 BizException message resolver 연결은 별개다.
