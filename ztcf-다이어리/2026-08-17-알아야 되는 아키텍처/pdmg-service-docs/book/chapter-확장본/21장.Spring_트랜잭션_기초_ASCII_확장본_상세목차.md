# 제21장. Spring 트랜잭션 기초 — ASCII 확장본 상세목차

> **작성 기준**
>
> - 핵심 근거: `chapter/21장.Spring 트랜잭션 기초.md`, `20.Tranaactional-rdwTransactionManager-Begin-1.md`, `71.Transaction Manager.md`, `01.트랜잭션처리 변경-1.md`.
> - RDW Bean: `rdwDataSource`, `rdwSqlSessionFactory`, `rdwSqlSessionTemplate`, `rdwTransactionManager(DataSourceTransactionManager)`가 같은 DataSource 축.
> - 주요 Facade: Manager 이름 명시, 조회 `readOnly=true`, 쓰기 `rollbackFor=Exception.class`.
> - Spring 기본: Proxy 외부호출, Thread-bound Connection, REQUIRED, Runtime/Error 기본 Rollback, checked 기본 자동 Rollback 아님.
> - 현재 PDMG에서 Facade Annotation이 항상 실제 최초 BEGIN이라는 설명은 금지. 실행모드별 outer boundary는 제22장에서 상세 판정.
