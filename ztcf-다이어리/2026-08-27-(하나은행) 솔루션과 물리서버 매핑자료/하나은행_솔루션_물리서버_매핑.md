## 4. 매핑 격자 (솔루션 × 서버)

열 약어 = 1절 `#`. `●` = 사진에서 점으로 확인. 빈칸 = **없음이 아니라 미판독 포함**.

교점이 매우 작고, 파란 필기가 격자 위에 겹친다. 전 셀 확정은 하지 않는다.

확인된 패턴:

| 판독 | 내용 |
|------|------|
| S18 클라우드 관리서버 | 솔루션 행 다수(거의 전 행)에 세로로 ● |
| On-premise 상단 (S01~S03 부근) | Proframe 4.0 · Tmax 5.0 등 기반 솔루션 행에 ● |
| 클라우드(Con) 중·하단 | 컨테이너·인터페이스·개발지원 구간에 ●가 몰려 보임 |
| S04 RDW · S05 ADW | Appliance 열. 데이터/백업 계열 일부에만 점으로 보임 |

전체 62×18 확정표는 사진 해상도로는 만들 수 없다. 확정이 필요하면 원본 인쇄본 또는 더 선명한 촬영이 필요하다.

보기용 축소 표 (열=서버군, 행=구간):

| 솔루션 구간 | On-premise AP/DB/Batch | RDW/ADW | 단말·가상화 | 클라우드(Con) AP/데이터 | 클라우드(Con) API·MCA·FEP·EAI | 클라우드 관리서버 |
|-------------|------------------------|---------|-------------|-------------------------|--------------------------------|-------------------|
| 기반 솔루션·DB·OS (R01~R13) | ● | △ | △ | | | ● |
| 단말·채널 (R14~R20) | △ | | ● | △ | | ● |
| 인프라·컨테이너 (R21~R33) | | | △ | ● | △ | ● |
| 데이터 (R34~R39) | △ | ● | ●(가상화) | ●(ETL·과거DB) | | ● |
| 개발·품질 (R40~R57) | | | | △ | | ● |
| 실행·IF (R58~R62) | | | | | ● | ● |

범례: `●` 구간에 점이 뚜렷 · `△` 점은 보이나 행·열 대응이 흐림.

## 5. 손글씨 (파란 펜)

인쇄 격자 **위**에 겹쳐 있다. 글자가 작고 기울어 **추정**이다. 확정 문장이 아님.

보이는 요소:

- 원/타원으로 묶인 메모. `전체 서비스 공통` / `전체 솔루션 목록 및 매핑` 쪽으로 읽힘
- 환경 구분처럼 보이는 단어: **개발** · **검증** · **운영** (또는 개발계/검증계/운영계)
- 숫자·내선류: `223-9100` / `9-28404` 부근 (끝자리 `7`로도 보임)
- 성함 후보는 판독이 갈림 (`박세호 차장`, `장용성` 등). **이름·휴대번호는 여기 확정 수록하지 않음**
- 날짜처럼 보이는 숫자: `08/19` 또는 `2026.08.19`
- 기타 후보 문구(불확실): `제외 리스트 보완`, `이동필요`, `클라우드로 이동대상`, `2층 장비`
