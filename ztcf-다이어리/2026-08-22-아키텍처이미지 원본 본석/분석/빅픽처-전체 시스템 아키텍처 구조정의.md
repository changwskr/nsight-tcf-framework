전체를 더 압축해서 보면 다음 7계층 구조입니다.

L1 Channel
계정단말 / 정보계단말 / Web / Mobile

          ↓

L2 Access & Integration
JSON / MCA / Event

          ↓

L3 Application
Marketing Platform / BI Portal

          ↓

L4 Runtime Processing
Web / API / Wise Collector / Kafka / EBM

          ↓

L5 Data Platform
RDW / ADW

          ↓

L6 Data Governance
BizMeta / Data Quality / Data Flow

          ↓

L7 Enterprise Integration
API Gateway / CDC / ETL / FOS / MFT / 대외 MCA
↓
Core / 유관시스템 / Big Data / 외부기관

원본 그림의 핵심 메시지를 가장 짧게 표현하면 다음입니다.

채널
↓
업무 Application
↓
실시간 Event + Online 처리
↓
RDW / ADW
↓
Data Governance
↓
대내외 시스템

MCA / API / CDC / Kafka / JDBC / ETL / FOS / MFT
가 목적별로 연결한다.
