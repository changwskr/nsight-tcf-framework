## 1. 한 줄 요약

차세대 정보계 **채널·업무 시스템**은 **UTF-8**, **ADW·RDW** 데이터베이스는 **MS949**로 정의한다. DB 연계 시 **연계 시스템(AP)** 이 MS949 변환을 수행하고, **API G/W(CruzAPIM)·GSE** 연계는 **전사 인터페이스 기준**에 따른 캐릭터셋 처리를 적용한다.

### 3.4 데이터 흐름 · Charset 변환점

| Flow ID | 흐름 | In Charset | Out Charset | 변환 주체 |
|---|---|---|---|---|
| **F01** | 정보단말 → MP AP | UTF-8 | UTF-8 (AP 내부) | 없음 |
| **F02** | MP AP → RDW INSERT/SELECT | UTF-8 (Java) | MS949 (DB) | **연계 AP (DAO/JDBC)** |
| **F03** | MP AP → ADW (배치/ETL) | UTF-8 | MS949 | **ETL·연계 AP** |
| **F04** | MP AP ↔ CruzAPIM ↔ 계정계 | UTF-8 (AP) | **전사 IF 규격** | API G/W · Adapter |
| **F05** | MP AP ↔ GSE ↔ 은행(법인) | UTF-8 (AP) | **전사 IF 규격** (FLAT) | GSE · Adapter |

## 4. 표준화 내용 (규칙)

| No | 규칙 | 내용 |
|---:|---|---|
| **R1** | 채널 Charset | 차세대 정보계 **채널 시스템** = **UTF-8** |
| **R2** | 업무 Charset | 차세대 정보계 **업무 시스템** = **UTF-8** |
| **R3** | DB Charset | **ADW · RDW** 데이터베이스 = **MS949** |
| **R4** | DB 변환 책임 | DB 연계 시 **DB와 연계하는 시스템(AP)** 이 **MS949 변환** 수행 |
| **R5** | 외부 연계 | **API G/W · GSE** 연계 — **전사 인터페이스 기준** 캐릭터셋 처리 |

## 5. 아키텍처 관점 핵심 정리

| 관점 | 확인되는 구조 |
|---|---|
| Application Layer | 채널·업무 전 구간 **UTF-8** (HTTP/JSON·온라인 AP) |
| Persistence Layer | **ADW/RDW = MS949** — 이기종 Charset |
| Boundary | **AP ↔ DB** 경계에서 **UTF-8 → MS949** 변환 |
| Integration | CruzAPIM/GSE = **전사 IF 표준** (FLAT/json 각각) |
| RDW/ADW 분리 | [전체_시스템_아키텍처](./전체_시스템_아키텍처_구조_정의_분석.md) 자원 분리와 **동일 DB 표준** |
| Test Impact | 한글·특수문자·**바이트 길이**(FLAT/DB 컬럼) 검증 필수 |

## 6. PDMG/TCF · Runtime 매핑

| 장표 영역 | PDMG/TCF 구현 | 비고 |
|---|---|---|
| HTTP/JSON (UTF-8) | `Content-Type: application/json;charset=UTF-8` | UI·Filter·Controller |
| JVM·컴파일 | `UTF-8` (`build.gradle`, `file.encoding`) | PDMG Baseline |
| JSON Body | `StandardCharsets.UTF_8` · CachedBodyFilter | `pdmg-fw` |
| 전문 필드 길이 | `CommonUtil` UTF-8 **byte 단위** truncate | FLAT/DB 길이와 **별도 검증** |
| RDW/ADW JDBC | Oracle Driver + AP Charset | **MS949 변환 — 장표 R4** · 구현 세부 Gap |
| CruzAPIM/GSE | Adapter/연계 모듈 | **전사 IF 규격** 따름 |

```text
[온라인 AP — Charset 경계]

Client (UTF-8 JSON)
  → DefaultFilter / JSON parse (UTF-8)
  → Service / DTO (Java String = UTF-16, wire = UTF-8)
  → DAO / JDBC
       │
       ├─ [R4] AP에서 MS949 변환 ──► RDW/ADW (MS949)
       │
       └─ [R5] CruzAPIM/GSE Adapter ──► 전사 IF Charset
```

> **Gap**: `pdmg-fw`는 **UTF-8** 기준으로 구현되어 있고, **MS949 변환 유틸·DAO 표준 훅은 Core에 고정되어 있지 않음**. RDW/ADW 실 DB Charset·JDBC `NLS` 설정과 **Runtime Validation** 필요.

## 8. 판독 제한·검증 필요 항목

| 항목 | 상태 |
|---|---|
| MS949 변환 **API/클래스** (pdmg-fw) | 장표는 **책임(AP)** 만 — 표준 구현 미기재 |
| Oracle **NLS_CHARSET** · JDBC URL | RDW/ADW 실환경 설정 — Inventory 확인 |
| FLAT 전문 **필드 길이** (byte vs char) | MCA/GSE — 전사 IF + Charset 교차 |
| ADW ETL (DataStage) Charset | 배치 경로 — R3/R4 별도 규격 |
| Package UI Charset | 장표상 **UTF-8** (채널과 동일) |
