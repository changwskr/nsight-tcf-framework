# 4 The K Core 업무 인터페이스 모델 - VI. Global Banking

> 원본: `원본/20200608_183747.jpg`  
> 문서: KB국민은행 · 전행 인터페이스 고도화 · 원문 전사(FACT)

## 본문

- **소제목:** Global Banking Interface Needs -
- **페이지:** 16 / KB국민은행
- **중심:** 글로벌 뱅킹 (내장 **n-KESA**) → 계정계 DB (`JDBC`)

### 채널 계층 (좌)

| 채널/관리 | → MCI 프로토콜 |
|-----------|----------------|
| 통합단말관리 | `http/http,xml` |
| 자동화기기관리 | `tcp/tcp,HLS` |
| 인터넷뱅킹 (연행 WEB·디지털뱅킹·태블릿 → http/html) | `http/http,json` |

- MCI(채널통합 내) → 글로벌 뱅킹: `http/http,json`

### 계정계·정보계 (우/중)

- **계정계 DB**
  - → 전일자 배치: `BCV`
  - → RDW: `CDC`
- **전일자 배치:** 전일자 · 배치 AP/DB
- **정보계 DB:** ODS → RDW → ADW, ODS/ADW → DM (`ETL`)
- **정보계 AP** ↔ ADW/DM: `JDBC`

### 통합·대외 (하단)

- **EAI(채널통합 외):** 배치 AP/DB · 정보계 AP · 외부채널 · 통합정보 AP · ROC 와 `FILE` 연계
- **외부채널:** 현지보고서 · 자금결제 · 펌뱅킹업체
- **통합정보 AP ↔ 통합정보 DB:** `JDBC` · 모델 연계 `IDM`
- **ROC:** MCI · 계정계 · 정보계 · 배치

## 핵심 포인트

- 글로벌 뱅킹은 **MCI(내) → n-KESA → 계정계 DB(JDBC)** 축이 핵심이다.
- 정보계는 **CDC/ETL**로 ODS–RDW–ADW–DM 파이프라인을 구성한다.
- 대외·배치·ROC 연계는 **EAI + FILE** 중심으로 통일한다.
