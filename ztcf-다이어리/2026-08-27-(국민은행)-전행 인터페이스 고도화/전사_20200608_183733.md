# 3 The K Core 업무 인터페이스 모델 - II. 마케팅 플랫폼

> 문서: KB국민은행 · 전행 인터페이스 고도화 · 원문 전사(FACT)

## 본문

**부제:** 마케팅 플랫폼 Interface Needs –

### 좌측 — 채널·관리
- 통합 단말 → 통합단말관리 (http/xml) → MCI
- 자동화기기 → 자동화기기관리 (tcp/ip/flat) → MCI
- 인뱅 WEB → 인터넷뱅킹(Quics) (http/http/json) → MCI
- 연계채널(SMS/DM/FAX) → 발송서버 → MCI·고객통지 (JDBC)
- CTI / 통신사 → 콜센터 IVR (tcp/ip/flat) → MCI
- EPS(권한정보) → MCI (FEP [판독])
- 클릭스트림 (log) → EBM (실시간 VT/EVT [판독])

### 중앙
- **MCI**
- **마케팅플랫폼** ← MCI (http/json), n-KESA
- **n-KESA**
- **EBM** — Offer 등으로 마케팅플랫폼 연계
- **고객통지** — MCI·발송서버·매체 EAI

### 우측 — 매체 EAI(내부) 및 백엔드
- 상품서비스 (http/xml, tcp/ip/flat)
- 금융복합/금융통합플랫폼 (http/json)
- 무인공과금, 신용리스크, 이미지정보, 인사, 국외점포
- Direct: 배치작업관리, FDS, 통합로그
- 상단 데이터: 빅데이터, RDW, ADW, 경영관리 및 지원 (ETL, CDC)

### 하단
- 대외 EAI (대외, 공동, 일괄, DMZ) — X.25 장비, 국민카드

- 페이지: 12 / KB국민은행

## TEXT 구성도

```text
 [채널]                    [코어]                         [내부/데이터]
 단말·ATM·인뱅·IVR ──► MCI ──http/json──► 마케팅플랫폼 ──► 매체 EAI(내부)
 EPS(FEP)            │                     ▲ n-KESA        │
 발송서버─JDBC───────┤                     │ Offer         ├ 상품·금융복합·통지·무인…
 클릭스트림─log──────┴──► EBM ─────────────┘               ├ ETL/CDC → RDW/ADW/빅데이터
                                                           └ Direct → 배치·FDS·통합로그
 대외기관─X.25─카드 ──────────────────────► 대외 EAI
```

## 핵심 포인트
- 마케팅플랫폼 Needs: MCI·n-KESA·EBM·고객통지를 중심축으로 구성
- 클릭스트림 → 실시간 EVT → EBM → Offer → 마케팅플랫폼
- 매체 EAI로 상품·금융복합·정보계·운영계 통합
- 발송서버·고객통지는 JDBC/Direct 연계
- 대외는 X.25·국민카드·대외 EAI
