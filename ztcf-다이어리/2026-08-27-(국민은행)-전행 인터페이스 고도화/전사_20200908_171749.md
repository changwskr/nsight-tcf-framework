## 본문

마케팅플랫폼(n-KESA)을 허브로, 채널·MCI·대외EAI·클릭스트림·EBM·고객통지와 우측 대내EAI·RDW/ADW/빅데이터·상품서비스가 연결되는 Interface Needs이다. 실시간 EVT·Offer·CDC·ETL·JDBC·Direct가 혼합된 이벤트·배치 병행 구조이다.

## TEXT 구성도

```
[상단 허브]
  마케팅플랫폼 (n-KESA) ★

[좌측: 채널·대외]
  통합단말 / 자동화기기 → MCI
  인뱅 WEB → 인터넷뱅킹(Quics) → MCI (http/json)
  연계채널(SMS/DM/FAX) → 발송서버
  CTI / 통신사 → 콜센터 IVR / 대외 EAI
  대외기관 / X.25 / 국민카드 → 대외 EAI (대외·공동·연합·DMZ)
  EPS(권한) ↔ MCI (F2F)
  통합단말관리 / 자동화기기관리 ↔ MCI
  클릭스트림 ← log ← 인터넷뱅킹·자동화기기

[이벤트·통지]
  클릭스트림 ── 실시간 EVT ──► EBM ──► 마케팅플랫폼
  EBM ── Offer ──► 인터넷뱅킹(Quics)
  고객통지 ↔ 발송서버·콜센터 IVR · JDBC ↔ 마케팅플랫폼

[우측: 내부·데이터]
  대내 EAI (내부)
  RDW / ADW / 빅데이터 ↔ 마케팅플랫폼 (ETL)
  경영관리 및 지원 ↔ 마케팅플랫폼 (CDC)
  상품서비스 (CDC), 금융복합플랫폼, 무인공과금,
  신용리스크, 이미지코드, 인사, 국외점포
  배치작업관리 / FDS / 통합로그 (Direct)

[주요 방식]
  http/xml · http/json · http/html · tcp/flat · X.25/flat
  F2F · JDBC · CDC · ETL · Direct · log · 실시간 EVT · Offer
```

## 핵심 포인트

- 마케팅플랫폼이 채널·EBM·고객통지·DW의 교차 허브
- 클릭스트림 → 실시간 EVT → EBM → Offer(인뱅) 실시간 마케팅 루프
- 상품·경영계는 CDC, 정보계는 ETL로 데이터 공급
- 대외·내부 EAI 이중 허브로 채널·백엔드 분리
