## 본문

**부제:** 상품 서비스 Interface Needs -

### 좌측 — 채널·대외
- 연계채널(SMS/DM/FAX) → EPS(권한정보), 발송서버
- 통합단말관리 ↔ 통합단말 (http/xml)
- 자동화기기·자동화기기관리 → MCI (http/xml, tcp/ip/flat)
- 인뱅 WEB / 인터넷뱅킹(Quics) → MCI, 클릭스트림 (http/xml, log)
- 클릭스트림 → 마케팅플랫폼 (Offer, 실시간 EVT, CDC 등)
- CTI / 콜센터 IVR → MCI (tcp/ip/flat)
- 통신사 → MCI (iso/xml [판독])
- 대외기관 → X.25 장비 → 국민카드 / 대외 EAI (x.25, tcp/ip/flat)

### 중앙 — 허브
- **MCI**
- **상품처리서비스** (z-KESA) — MCI와 SNA/SNA/Net[판독] 연계, NDM·CICS 연동
- **대외 EAI** (대외, 공동, 일괄, DMZ)

### 우측 — 내부·정보계
- **대내(매체) EAI (내부)** — F2F, http/json, http/xml 등
- 경영관리 및 지원, RDW, ADW, 빅데이터 (ETL, F2F)
- 마케팅플랫폼, 금융복합플랫폼, 고객통지 (JDBC, CDC)
- 무인공과금, 신용리스크, 이미지콜드[판독], 인사, 국외점포
- 배치작업관리, FDS, 통합로그 (Direct), 발송서버

- 페이지: 11 / KB국민은행

## 핵심 포인트
- 상품서비스 Interface Needs: MCI·상품처리(z-KESA)·대내/대외 EAI 중심
- 채널은 HTTP/XML·TCP/Flat, 코어는 SNA 계열 연계
- 클릭스트림 기반 실시간 EVT/Offer → 마케팅플랫폼
- 정보계는 ETL·CDC·F2F로 RDW/ADW/빅데이터 연결
- Direct/JDBC로 배치·FDS·통합로그·통지 연계
