## 본문

콜센터(마케팅플랫폼)를 중심으로 단말·IVR·멀티미디어 채널, MCI/n-KESA, 대내·대외 EAI, 정보계(RDW/ADW/빅데이터) 및 내부 업무 시스템 간의 Interface Needs를 정의한 다이어그램이다. 음성·SIP 계열 프로토콜과 HTTP/JSON·ETL/CDC가 한 장에 공존한다.

## TEXT 구성도

  ──http(http) xml──► MCI ──http(http) xml──► 콜센터(마케팅플랫폼)

### 영역별 요약

| 영역 | 주요 구성요소 | 대표 프로토콜 |
|------|---------------|---------------|
| 단말·권한 | 통합단말, 통합단말관리, EPS, 발송서버 | http(http) xml |
| 멀티미디어·CTI | 메일/채팅, 보이는 ARS, TTS/SR, IVR, 교환기, 녹취, PDS, FAX | tcp, tsap, SIP, E1, H.323 |
| 중계 | MCI, n-KESA | http(http) xml |
| 코어 | 콜센터(마케팅플랫폼), 고객상담 | — |
| 대외 | 대외 EAI, 대외기관, X.25, 국민카드 | tcp(tcp) flat |
| 대내 | 대내 EAI ↔ 상품·리스크·이미지 등 | sna flat, http(tcp) json |
| 데이터 | IFRS, RDW, ADW, 빅데이터, 경영관리 | ETL, F2F, CDC |
| 공통 | 배치작업관리, FDS, 통합로그, 고객통지 | Direct, JDBC, TCP/IP |

## 핵심 포인트

- **계층화**: 채널=MCI, 내부=대내 EAI, 외부=대외 EAI로 인터페이스 레이어를 분리.
- 콜센터 특유의 **음성·교환기 프로토콜(SIP/E1/H.323)** 과 일반 업무 HTTP/JSON이 병행.
- 콜센터 발생 데이터를 RDW/ADW/빅데이터로 적재 후 마케팅플랫폼에서 재사용하는 선순환 구조.
- DMZ 대외 연계와 FDS·통합로그 등 공통 보안·운영 모듈 포함.
