> 문서: KB국민은행 · 전행 인터페이스 고도화 · 원문 전사(FACT)

## 본문

**부제:** 금융복합 플랫폼 Interface Needs –

### 중앙 코어
- **금융복합 플랫폼** (점선 영역) — 내부 **n-KESA**
- **MCI** (좌측)
- **통합인증** (MCI 하단)

### 좌측 — 채널·대외
- EPS(권한정보) → MCI (P2P)
- 종합 단말 → 통합단말관리 → MCI (http/http/xml)
- 자동화기기 → 자동화기기관리 → MCI (tcp/tcp/flat)
- CTI·통신사 → 콜센터 IVR → MCI (tcp/tcp/flat)
- 인뱅 WEB → 인터넷뱅킹(UI) → MCI (http/http/json)
- 연계채널(SMS/DM/FAX) → 발송서버 → 고객통지 (JDBC/Direct)
- 대외기관·국민카드 → X.25 장비 → 대외 EAI (대외, 공동, 일괄[판독:일몰?], DMZ)

### 우측 — 매체 EAI(내부)·데이터
- 빅데이터, ADW, RDW, 경영관리 및 지원 (ETL, EIL[판독], CDC)
- 상품서비스, 마케팅플랫폼, 고객통지, 무인공과금, 신용리스크, 이미지코드[판독], 인사, 국외점포
- Direct: 메시지관리[판독:배치작업관리?], FDS, 통합로그

### 강조 흐름
- 인터넷뱅킹 → 클릭스트림(log) → 실시간 EVT → 마케팅플랫폼 (빨간 선)
- 마케팅플랫폼 → 금융복합 플랫폼 (Offer, 보라 선)

- 페이지: 13 / KB국민은행

## TEXT 구성도

```text
 [채널]                         [금융복합 플랫폼]              [내부/데이터]
 EPS(P2P) ──────────────┐      ┌──────────────────┐
 단말관리(http/xml) ────┤      │                  │     매체 EAI(내부)
 ATM관리(tcp/flat) ─────┼─►MCI─►│  n-KESA          │◄───► 상품·마케팅·통지·무인…
 인뱅(http/json) ───────┤      │  금융복합 플랫폼  │      리스크·인사·국외
 IVR(tcp/flat) ─────────┘      └────────┬─────────┘      RDW/ADW/빅데이터(ETL/CDC)
 통합인증                              │
                                      Offer ◄── 마케팅플랫폼 ◄── 클릭스트림(log/실시간EVT)
 발송서버 ─JDBC/Direct─► 고객통지
 대외기관─X.25─카드 ───► 대외 EAI
                      Direct → 메시지관리·FDS·통합로그
```

## 핵심 포인트
- 금융복합 플랫폼 Needs: MCI + n-KESA를 코어로 한 옴니채널 연계
- 채널별 프로토콜 차별(P2P·HTTP/XML·HTTP/JSON·TCP/Flat)
- 마케팅 Offer·클릭스트림 실시간 EVT와 교차 연계
- 매체 EAI로 내부 업무·정보계 통합, 대외 EAI로 외부 연계
- 통합인증·발송/통지·운영(Direct) 구성요소 포함
