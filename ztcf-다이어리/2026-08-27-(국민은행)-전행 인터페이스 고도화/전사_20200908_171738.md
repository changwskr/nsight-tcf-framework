## 본문

MCI·코어·데이터계(RDW/ADW/빅데이터)·마케팅·고객통지를 상단에 두고, 중앙에 내부·대외·공동망·일괄·DMZ EAI 5영역 허브를 배치한 어플리케이션 통합 논리도이다. 하단 단위업무·플랫폼이 EAI를 통해 상위와 연동되며 CDC/ETL·동기/비동기·다중 포맷이 혼용된다.

## TEXT 구성도

```
[상단: 코어·데이터·마케팅]
  MCI ← 통합단말관리, EPS, 콜센터 IVR, 태블릿브랜치, 인뱅(Quics)
  상품처리서비스 (z-KESA, M/F) ── 전행고객·전행상품 코어
  RDW (Oracle/Unix, 실시간 SOR) ← CDC ← 상품처리
  ADW (Sybase/UNIX, 통합 SOR)  ← ETL ← RDW / CDC·ETL ← 상품처리
  빅데이터 (Cloud) ← ETL ← ADW
```

## 핵심 포인트

- EAI를 내부·대외·공동망·일괄·DMZ로 역할 분리
- 상품처리 → CDC → RDW → ETL → ADW → 빅데이터 → 마케팅 데이터 파이프라인
- DMZ EAI가 대외기관·국민카드·국외점포·발송 접점
- 동기/비동기·HTTP/Socket·전문/F2F/D2D·Flat/XML/JSON 등 표준 연계 체계
