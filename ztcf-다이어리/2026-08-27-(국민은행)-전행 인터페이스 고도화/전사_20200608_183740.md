# 3 The K Core 업무 인터페이스 모델 - Ⅳ. 경영관리

> 원본: `원본/20200608_183740.jpg`  
> 문서: KB국민은행 · 전행 인터페이스 고도화 · 원문 전사(FACT)

## 본문

- **소제목:** 경영관리 Interface Needs -
- **페이지:** 14 / KB국민은행
- **중심 시스템:** 경영관리 시스템 (내장 **u-KESA**)
- **중계 허브:** MCI · 대외 EAI(대외/공동/DMZ/연계) · 대내 EAI(내부)
- **채널/단말(좌):** 종합단말, 모바일(App/Web), 정보계 종합단말, 모바일 Web, WebPF
- **데이터·분석(우/상):** IFRS, 빅데이터, 금융복합 플랫폼, RDW, ADW
- **대내 업무(우하):** 상품서비스, 마케팅플랫폼, 무인공과금, 신용리스크, 이미지콜드, 인사, 국외점포, 보고서서버
- **공통/배치:** 배치작업관리, FDS, 통합로그, 고객통지, 발송서버

### 주요 인터페이스 프로토콜

| 구간 | 프로토콜 |
|------|----------|
| 종합단말 / 모바일 Web → MCI | `http(http): xml` |
| MCI → 경영관리 | `http(http): xml` |
| 대외기관 → X.25 장비 | `X.25` |
| 국민카드 → 대외 EAI | `tcp(tcp): flat` |
| 대외 EAI → 경영관리 | `http(tcp): xml` |
| 경영관리 ↔ 대내 EAI | `http(tcp): xml` |
| 대내 EAI → 상품서비스 | `sna(sna): flat` |
| 대내 EAI → 마케팅/무인공과금/신용리스크/이미지콜드/국외점포 | `http(tcp): json` |
| 대내 EAI → 인사 | `tcp(tcp): flat` |
| 금융복합 ↔ RDW / RDW ↔ ADW / 빅데이터→ADW | `F2F`, `ETL` |
| 대내 EAI → ADW/RDW | `ETL`, `CDC` |
| ADW/빅데이터 → IFRS | `ETL` |
| 배치/FDS/통합로그 → 경영관리 | `Direct` |
| 고객통지 → 발송서버 | `TCP/IP`, `JDBC` |

## 핵심 포인트

- 경영관리 코어를 중심으로 **MCI / 대외 EAI / 대내 EAI** 삼각 중계 체계를 구성한다.
- 채널·대외는 주로 **XML/Flat**, 대내 업무는 **JSON**, 정보계는 **ETL·CDC·F2F**로 이원화한다.
- 경영관리 내부 표준 프레임은 **u-KESA**로 표기된다.
