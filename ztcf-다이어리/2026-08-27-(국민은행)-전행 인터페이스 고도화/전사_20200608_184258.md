# 선도개발 시스템 Network구성도

> 원본: `원본/20200608_184258.jpg`  
> 문서: KB국민은행 · 전행 인터페이스 고도화 · 원문 전사(FACT)

## 본문

- **섹션:** V. 시스템 구성도 / 3. H/W 구성도
- **대상:** 여의도 2센터 Network — **As-Is** / **To-Be** 대비
- **하단:** Post차세대 구축전략 컨설팅 7 / KB국민은행

### 네트워크 구역 (세로)

| 구역 | 구성 |
|------|------|
| EXT | 라우터 · EXT 백본 · EXT 방화벽(FW) |
| DMZ | LOC 백본 · INT 방화벽(FW) |
| 내부 | INT 백본 · 서버팜 백본 · Core 백본 |

### As-Is (상단)

- DMZ: **비대면채널** 서버군
- Core: **EAI 테스트자동화** 등
- 흐름: 라우터 → EXT 백본 → EXT FW → LOC 백본 → INT FW → INT 백본 → 서버팜 백본 → Core 백본

### To-Be (하단, 여의도 2센터)

- **SDN** 스위치가 DMZ·내부 각각에 도입
- **인터넷뱅킹(DMZ):** 화면 WEB(Cloud) · WAS(Cloud) · DB(베어메탈) · 멀티로그인차단(베어메탈)
- **금융플랫폼(내부):** 마케팅Hub · 무인공과금 · 금융복합 · 전문통합관리 (Cloud AP / 베어메탈 DB)
- **영업점시스템(내부):** 단말 AP/DB
- **Legacy L2:** MCI(Oracle UNIX) · EAI(IBM UNIX) 연결

### 연결 포인트 (빨간 말풍선)

1. DMZ: As-Is LOC 백본 ↔ To-Be LOC 백본  
2. 내부: As-Is Core 백본 ↔ To-Be Core 백본

## 핵심 포인트

- As-Is와 To-Be를 **동일 EXT–DMZ–내부 계층** 위에 상·하로 대비한다.
- To-Be는 **SDN** 도입과 Cloud/Baremetal 서버 배치가 특징이다.
- 이행기 **LOC·Core 백본 물리 연결**로 As-Is/To-Be를 병행 연동한다.
- Legacy(MCI/EAI UNIX)는 L2 스위치로 To-Be에 접속한다.
